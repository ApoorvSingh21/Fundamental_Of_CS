======================================================================
14.1 WHAT IS A CONTEXT-FREE LANGUAGE?
======================================================================

Before studying its properties, recall what a CFL is.

A Context-Free Language is a language that can be generated by a
Context-Free Grammar (CFG).

A CFG is formally represented as:

        G = (V, Σ, P, S)

where:

        V = set of variables/non-terminals
        Σ = set of terminals
        P = production rules
        S = start symbol

Example:

        S → aSb
        S → ε

This grammar generates:

        ε
        ab
        aabb
        aaabbb
        aaaabbbb
        ...

Therefore:

        L = { aⁿbⁿ | n ≥ 0 }

is a Context-Free Language.

It can also be recognized by a Pushdown Automaton (PDA).

So we have:

        CFG
         |
         v
        CFL
         ^
         |
        PDA

This relationship is extremely important.

======================================================================
14.2 WHAT DOES "CLOSED UNDER AN OPERATION" MEAN?
======================================================================

This is one of the most important definitions in this chapter.

Suppose we have a class of languages C and an operation ⊙.

We say:

        C is CLOSED under ⊙

if applying ⊙ to languages belonging to C always produces
another language belonging to C.

In simple words:

        "The operation does not take us outside the class."

Example:

Suppose A and B are CFLs.

If:

        A ∪ B

is always a CFL,

then CFLs are closed under UNION.

Mathematically:

        A, B ∈ CFL
        ⇒
        A ∪ B ∈ CFL

Similarly:

        A, B ∈ CFL
        ⇒
        AB ∈ CFL

would mean CFLs are closed under concatenation.

----------------------------------------------------------------------
REAL-WORLD ANALOGY
----------------------------------------------------------------------

Imagine a container labeled:

        "CFL"

You put two CFLs inside an operation.

If the result is still inside the CFL container:

        CFL + operation → CFL

then CFLs are closed under that operation.

If the result can leave the container:

        CFL + operation → possibly NOT CFL

then CFLs are not closed under that operation.

======================================================================
14.3 CLOSURE PROPERTIES OF CFLs
======================================================================

Context-Free Languages ARE closed under:

        ✓ Union
        ✓ Concatenation
        ✓ Kleene Star
        ✓ Kleene Plus
        ✓ Reversal
        ✓ Homomorphism
        ✓ Inverse Homomorphism

Context-Free Languages are NOT generally closed under:

        ✗ Intersection
        ✗ Complement
        ✗ Difference

This list is extremely important for B.Tech and GATE examinations.

Remember:

        CFL:
        ------------------------------------------------
        UNION              ✓
        CONCATENATION      ✓
        STAR               ✓
        PLUS               ✓
        REVERSAL           ✓
        HOMOMORPHISM       ✓
        INVERSE HOMOMORPH. ✓
        INTERSECTION       ✗
        COMPLEMENT         ✗
        DIFFERENCE         ✗
        ------------------------------------------------

======================================================================
14.4 CLOSURE UNDER UNION
======================================================================

Suppose:

        L₁ and L₂

are CFLs.

Then:

        L₁ ∪ L₂

is also a CFL.

Union means:

        L₁ ∪ L₂ = strings that belong to L₁ OR L₂

Example:

        L₁ = { aⁿbⁿ | n ≥ 0 }

        L₂ = { cⁿdⁿ | n ≥ 0 }

Both are CFLs.

Therefore:

        L₁ ∪ L₂

is also a CFL.

----------------------------------------------------------------------
WHY?
----------------------------------------------------------------------

Suppose:

        G₁ generates L₁
        G₂ generates L₂

Create a new start symbol S:

        S → S₁
        S → S₂

where S₁ is the start symbol of G₁
and S₂ is the start symbol of G₂.

Therefore the new grammar can generate strings from either language.

ASCII idea:

                    S
                   / \
                  /   \
                S₁     S₂
                |       |
               G₁      G₂
                |       |
               L₁      L₂

Hence:

        CFL ∪ CFL = CFL

======================================================================
14.5 CLOSURE UNDER CONCATENATION
======================================================================

If L₁ and L₂ are CFLs, then:

        L₁L₂

is also a CFL.

Concatenation means:

        Take one string from L₁
        followed by one string from L₂.

Example:

        L₁ = { aⁿ | n ≥ 0 }

        L₂ = { bᵐ | m ≥ 0 }

Then:

        L₁L₂ = { aⁿbᵐ | n,m ≥ 0 }

which is a CFL.

----------------------------------------------------------------------
GRAMMAR IDEA
----------------------------------------------------------------------

Suppose:

        S₁ generates L₁
        S₂ generates L₂

Create:

        S → S₁S₂

Then the grammar first generates a string from L₁ and then a string
from L₂.

ASCII:

        S
        |
        v
       S₁ S₂
       |   |
      L₁  L₂

Therefore:

        CFL · CFL = CFL

======================================================================
14.6 CLOSURE UNDER KLEENE STAR
======================================================================

If L is a CFL, then:

        L*

is also a CFL.

Recall:

        L* = zero or more repetitions of strings from L.

Example:

        L = {ab}

Then:

        L* = { ε, ab, abab, ababab, ... }

This is a CFL.

----------------------------------------------------------------------
GRAMMAR IDEA
----------------------------------------------------------------------

Suppose S₁ generates L.

We can construct:

        S → S₁S
        S → ε

This allows:

        zero repetitions
        one repetition
        two repetitions
        three repetitions
        ...

ASCII:

                    +------+
                    |      |
                    v      |
        S --------> S₁ ----+
        |
        |
        +------> ε

Therefore:

        CFL* = CFL

======================================================================
14.7 CLOSURE UNDER KLEENE PLUS
======================================================================

Kleene Plus is:

        L⁺ = one or more repetitions of strings from L.

Relationship:

        L⁺ = LL*

or equivalently:

        L⁺ = L*L

If L is CFL, then L⁺ is also CFL.

Example:

        L = {ab}

Then:

        L⁺ = {ab, abab, ababab, ...}

Since CFLs are closed under concatenation and Kleene star:

        L⁺ is CFL.

IMPORTANT:

        L* contains ε.

        L⁺ does not necessarily contain ε.

Example:

        L = {a}

        L* = {ε, a, aa, aaa, ...}

        L⁺ = {a, aa, aaa, ...}

======================================================================
14.8 CLOSURE UNDER REVERSAL
======================================================================

If L is a CFL, then:

        Lᴿ

is also a CFL.

Reversal means reversing every string.

Example:

        L = {abc}

Then:

        Lᴿ = {cba}

For a language:

        L = {ab, aab}

we get:

        Lᴿ = {ba, baa}

----------------------------------------------------------------------
GRAMMAR INTUITION
----------------------------------------------------------------------

If a CFG generates strings in a particular order, its production
structure can be reversed appropriately to generate reversed strings.

Therefore:

        CFL reversal = CFL

This property is often useful in proofs.

======================================================================
14.9 HOMOMORPHISM
======================================================================

A homomorphism is a function that maps symbols to strings while
preserving concatenation.

Suppose:

        h(a) = 0
        h(b) = 11

Then:

        h(ab) = h(a)h(b)

              = 0 · 11

              = 011

For:

        w = aabb

we get:

        h(aabb)
        = h(a)h(a)h(b)h(b)
        = 0 0 11 11
        = 001111

If L is a CFL, then:

        h(L)

is also a CFL.

Therefore CFLs are closed under homomorphism.

----------------------------------------------------------------------
IMPORTANT IDEA
----------------------------------------------------------------------

A homomorphism replaces each symbol consistently.

Example:

        a → x
        b → yz

Then:

        abba

becomes:

        x yz yz x

        = xyzzyzx

======================================================================
14.10 INVERSE HOMOMORPHISM
======================================================================

CFLs are also closed under inverse homomorphism.

Suppose:

        h : Σ* → Γ*

Then the inverse homomorphic image of a language L is:

        h⁻¹(L)

It means:

        all strings whose homomorphic images belong to L.

Formally:

        h⁻¹(L)
        = { w | h(w) ∈ L }

The important exam fact is:

        If L is CFL,
        then h⁻¹(L) is also CFL.

======================================================================
14.11 INTERSECTION — NOT CLOSED
======================================================================

This is VERY IMPORTANT.

Context-Free Languages are NOT closed under arbitrary intersection.

That means:

        L₁ and L₂ are CFLs

does NOT guarantee:

        L₁ ∩ L₂

is CFL.

----------------------------------------------------------------------
CLASSIC EXAMPLE
----------------------------------------------------------------------

Consider:

        L₁ = { aⁱbⁱcʲ | i,j ≥ 0 }

This is CFL.

A grammar can make equal numbers of a's and b's.

Now consider:

        L₂ = { aⁱbʲcʲ | i,j ≥ 0 }

This is also CFL.

A grammar can make equal numbers of b's and c's.

Now intersect them:

        L₁ ∩ L₂

A string must satisfy BOTH conditions:

        number of a = number of b

AND

        number of b = number of c

Therefore:

        number of a = number of b = number of c

Hence:

        L₁ ∩ L₂
        = { aⁿbⁿcⁿ | n ≥ 0 }

But:

        { aⁿbⁿcⁿ | n ≥ 0 }

is NOT context-free.

Therefore CFLs are not closed under intersection.

----------------------------------------------------------------------
VERY IMPORTANT LOGIC
----------------------------------------------------------------------

Do NOT say:

        "Intersection of two CFLs is never CFL."

That is WRONG.

Correct statement:

        "CFLs are not closed under intersection."

Some particular intersections can still be CFLs.

For example:

        L₁ = {a*}
        L₂ = {a*}

Then:

        L₁ ∩ L₂ = {a*}

which is CFL.

======================================================================
14.12 COMPLEMENT — NOT CLOSED
======================================================================

CFLs are NOT closed under complement.

That means:

        L is CFL

does NOT guarantee:

        L̅ is CFL.

Here:

        L̅ = Σ* - L

is the complement of L with respect to alphabet Σ.

----------------------------------------------------------------------
IMPORTANT CONNECTION
----------------------------------------------------------------------

For regular languages:

        REGULAR languages are closed under complement.

For CFLs:

        CFLs are NOT closed under complement.

This difference is extremely important.

======================================================================
14.13 DIFFERENCE — NOT CLOSED
======================================================================

CFLs are also NOT closed under difference.

Difference is:

        L₁ - L₂

meaning:

        strings belonging to L₁
        but NOT belonging to L₂.

Using:

        L₁ - L₂ = L₁ ∩ L̅₂

If CFLs were closed under difference, then because CFLs are closed
under union and other operations, this would lead to closure under
intersection.

But CFLs are not closed under intersection.

Therefore:

        CFLs are NOT closed under difference.

======================================================================
14.15 CFL PUMPING LEMMA
======================================================================

Now we move to a very important topic.

The CFL Pumping Lemma is primarily used to prove:

        A language is NOT context-free.

It is similar in spirit to the pumping lemma for regular languages,
but its structure is different.

----------------------------------------------------------------------
WHY DO WE NEED IT?
----------------------------------------------------------------------

Suppose someone gives you:

        L = { aⁿbⁿcⁿ | n ≥ 0 }

and asks:

        "Is L context-free?"

Constructing a CFG directly may be difficult.

The CFL Pumping Lemma can help prove that L is NOT CFL.

======================================================================
14.16 INTUITION OF CFL PUMPING
======================================================================

A sufficiently long string generated by a CFG must contain a portion
that can be repeated while remaining inside the language.

Instead of one pumped section, the CFL pumping lemma uses TWO pieces
that can be pumped together.

The basic pattern is:

        uvxyz

where:

        v and y

are the pieces that can be pumped.

The pumped string has the form:

        u vⁱ x yⁱ z

for i ≥ 0.

ASCII representation:

        String:

        +---+---+---+---+---+
        | u | v | x | y | z |
        +---+---+---+---+---+

                  ↑       ↑
                  |       |
               pump v   pump y

For every i ≥ 0:

        u vⁱ x yⁱ z

must remain in the language if the language is CFL.

======================================================================
14.17 FORMAL STATEMENT OF CFL PUMPING LEMMA
======================================================================

If L is a context-free language, then there exists a pumping length p
such that every string w ∈ L with:

        |w| ≥ p

can be written as:

        w = uvxyz

such that:

        1. |vxy| ≤ p

        2. |vy| > 0

        3. For every i ≥ 0,

           uvⁱxyⁱz ∈ L

This is the formal statement you should know for exams.

----------------------------------------------------------------------
MEANING OF EACH CONDITION
----------------------------------------------------------------------

Condition 1:

        |vxy| ≤ p

The middle section cannot be too large.

Condition 2:

        |vy| > 0

At least one of v or y must contain a symbol.

They cannot both be empty.

Condition 3:

        uvⁱxyⁱz ∈ L

We can pump v and y together.

For example:

        i = 0

gives:

        uxz

        i = 1

gives:

        uvxyz

        i = 2

gives:

        uvvxyyz

        i = 3

gives:

        uvvvxyyyz

and so on.

======================================================================
14.18 VISUALIZATION OF THE PUMPING LEMMA
======================================================================

Original:

        u | v | x | y | z

        [----- vxy -----]
        [------ length ≤ p ------]

Pump i = 0:

        u | x | z

Pump i = 1:

        u | v | x | y | z

Pump i = 2:

        u | vv | x | yy | z

Pump i = 3:

        u | vvv | x | yyy | z

Therefore:

        u vⁱ x yⁱ z

must remain in L.

======================================================================
14.19 THE MOST IMPORTANT LOGICAL POINT
======================================================================

The pumping lemma says:

        IF L IS CFL
        THEN every sufficiently long string
        has a valid pumping decomposition.

To prove that L is NOT CFL:

        Assume L is CFL.

        ↓

        Apply pumping lemma.

        ↓

        Choose a suitable long string w.

        ↓

        Consider ALL valid decompositions.

        ↓

        Show that some pumping value i
        causes the resulting string to leave L.

        ↓

        CONTRADICTION.

        Therefore L is NOT CFL.

======================================================================
14.20 PROVING {aⁿbⁿcⁿ | n ≥ 0} IS NOT CFL
======================================================================

This is one of the most important examples.

Language:

        L = { aⁿbⁿcⁿ | n ≥ 0 }

We want to prove:

        L is NOT context-free.

----------------------------------------------------------------------
STEP 1 — ASSUME THE OPPOSITE
----------------------------------------------------------------------

Assume:

        L is CFL.

Then the CFL pumping lemma applies.

Let:

        p = pumping length.

----------------------------------------------------------------------
STEP 2 — CHOOSE A STRING
----------------------------------------------------------------------

Choose:

        w = aᵖbᵖcᵖ

Clearly:

        w ∈ L

and:

        |w| = 3p ≥ p.

----------------------------------------------------------------------
STEP 3 — APPLY THE LEMMA
----------------------------------------------------------------------

The lemma says:

        w = uvxyz

such that:

        |vxy| ≤ p
        |vy| > 0

and:

        uvⁱxyⁱz ∈ L

for every i ≥ 0.

----------------------------------------------------------------------
STEP 4 — ANALYZE vxy
----------------------------------------------------------------------

The string is:

        aaaa...aaaa bbbb...bbbb cccc...cccc
              p            p            p

Since:

        |vxy| ≤ p

the substring vxy cannot cover all three blocks.

It can lie:

        entirely within a's

OR

        entirely within b's

OR

        entirely within c's

OR

        across the a/b boundary

OR

        across the b/c boundary.

It cannot cover both boundaries.

----------------------------------------------------------------------
STEP 5 — PUMP
----------------------------------------------------------------------

Choose:

        i = 0

Then:

        uv⁰xy⁰z

        = uxz

We remove v and y.

Since:

        |vy| > 0

at least one symbol is removed.

Therefore the resulting string no longer has equal numbers of
a's, b's and c's.

Hence:

        uxz ∉ L

But the pumping lemma required:

        uxz ∈ L

CONTRADICTION.

Therefore:

        {aⁿbⁿcⁿ | n ≥ 0}

is NOT context-free.

======================================================================
14.21 IMPORTANT WARNING ABOUT PUMPING LEMMA
======================================================================

This is one of the biggest sources of mistakes.

To prove non-CFL, you cannot simply choose one decomposition and
show that it fails.

You must handle ALL possible valid decompositions.

The logic is:

        For every valid decomposition
        there exists an i
        such that the pumped string is not in L.

NOT:

        There exists one decomposition
        that fails.

This distinction is extremely important in GATE questions.

======================================================================
14.22 CFL PUMPING LEMMA VS REGULAR PUMPING LEMMA
======================================================================

Regular-language pumping lemma:

        w = xyz

with:

        xyⁱz

CFL pumping lemma:

        w = uvxyz

with:

        uvⁱxyⁱz

Comparison:

        Regular:
        +---+---+---+
        | x | y | z |
        +---+---+---+
              ↑
             pump

        CFL:
        +---+---+---+---+---+
        | u | v | x | y | z |
        +---+---+---+---+---+
              ↑       ↑
             pump    pump

The CFL lemma has two pumpable regions:

        v and y

and they are pumped together.

======================================================================
14.23 COMMON NON-CFL LANGUAGES
======================================================================

Important examples include:

        {aⁿbⁿcⁿ | n ≥ 0}

        {ww | w ∈ Σ*}

        {aⁿ | n is ...}
        (depending on the exact condition)

        {aⁿbⁿcⁿdⁿ | n ≥ 0}

        Certain languages requiring multiple independent
        counting relationships.

However, be careful:

Not every language that "looks complicated" is non-CFL.

For example:

        {aⁿbⁿ | n ≥ 0}

IS CFL.

It can be generated by:

        S → aSb
        S → ε

And recognized by a PDA.

======================================================================
14.24 PALINDROMES AND CFLs
======================================================================

A palindrome reads the same from left to right and right to left.

Examples:

        ε
        a
        b
        aba
        abba
        aabaa

The language of palindromes over {a,b} is actually context-free.

A CFG can be:

        S → aSa
        S → bSb
        S → a
        S → b
        S → ε

Therefore:

        Palindromes are CFL.

IMPORTANT:

Do not memorize:

        "Palindrome = non-CFL"

That is FALSE.

However, some more complex palindrome-related languages are not CFL.

======================================================================
14.25 WHY PDA CANNOT HANDLE EVERYTHING
======================================================================

A PDA has:

        finite control + one stack

The stack is excellent for handling one major nested dependency.

Example:

        aⁿbⁿ

The PDA can:

        read a's → push
        read b's → pop

ASCII:

        Input:
        a a a b b b
        | | | | | |
        v v v v v v

        Stack:
        push push push
              ↓
        pop  pop  pop

But for:

        aⁿbⁿcⁿ

the machine needs to remember and compare two independent
relationships:

        a count = b count

AND

        b count = c count

A single stack cannot generally maintain the required information.

This gives intuition for why:

        {aⁿbⁿcⁿ}

is not CFL.

======================================================================
14.26 OGDEN'S LEMMA
======================================================================

The CFL Pumping Lemma is useful, but sometimes it is not strong
enough to prove that a language is non-context-free.

For such situations, Ogden's Lemma can be useful.

Ogden's Lemma is a stronger pumping result for CFLs.

----------------------------------------------------------------------
MAIN IDEA
----------------------------------------------------------------------

Instead of simply taking a long string, we can MARK positions in the
string.

The marked positions help us control where the pumping occurs.

This gives us more flexibility than the ordinary CFL pumping lemma.

----------------------------------------------------------------------
INTUITION
----------------------------------------------------------------------

CFL Pumping Lemma:

        Choose a long string
                |
                v
        Find uvxyz
                |
                v
        Pump v and y

Ogden's Lemma:

        Choose a string
                |
                v
        MARK selected positions
                |
                v
        Obtain uvxyz
                |
                v
        Pump selected regions
                |
                v
        Derive contradiction

======================================================================
14.27 WHY OGdEN'S LEMMA IS NEEDED
======================================================================

Sometimes a language has a structure where choosing any arbitrary
long string does not give enough control over the positions v and y.

By marking positions, Ogden's lemma allows us to force the pumping
parts to interact with the important regions of the string.

Therefore:

        Ordinary CFL Pumping Lemma
                    ↓
              useful but limited
                    ↓
              Ogden's Lemma
                    ↓
          stronger proof technique

For beginner/B.Tech study:

        First master CFL Pumping Lemma.

Then study Ogden's Lemma.

======================================================================
14.28 IMPORTANT DIFFERENCE:
CFL CLOSURE VS CFL PUMPING LEMMA
======================================================================

Closure properties answer:

        "What happens when I perform an operation?"

Example:

        Is L₁ ∪ L₂ a CFL?

Pumping lemma answers:

        "Can I prove that a language is NOT CFL?"

Therefore:

        Closure properties
        → classify behavior under operations

        Pumping lemma
        → prove non-context-freeness

======================================================================
14.29 COMMON MISTAKES
======================================================================

MISTAKE 1:
    Thinking CFLs are closed under intersection.

WRONG.

Correct:

    CFLs are NOT closed under arbitrary intersection.


MISTAKE 2:
    Thinking CFLs are closed under complement.

WRONG.

Correct:

    CFLs are NOT closed under complement.


MISTAKE 3:
    Confusing CFL pumping lemma with regular pumping lemma.

Regular:

    xyz

CFL:

    uvxyz


MISTAKE 4:
    Pumping only one section.

Wrong.

CFL pumping pumps:

    v and y

together.


MISTAKE 5:
    Choosing only one decomposition.

For a non-CFL proof, you must consider every valid decomposition.


MISTAKE 6:
    Assuming that satisfying the pumping lemma proves CFL.

WRONG.

The pumping lemma gives a NECESSARY condition.

It is not a complete characterization.

A language satisfying the pumping property is not automatically
proven to be CFL by that fact alone.


MISTAKE 7:
    Thinking every complicated language is non-CFL.

Wrong.

Always use a valid proof technique.

======================================================================
14.30 NECESSARY VS SUFFICIENT CONDITION
======================================================================

This is very important.

For a CFL:

        CFL
         ↓
        satisfies CFL pumping property

Therefore:

        CFL → Pumping property

But the reverse implication cannot generally be used as:

        Pumping property → CFL

So the pumping lemma is mainly useful for proving:

        NOT CFL

not for proving:

        CFL

To prove a language IS CFL, better approaches include:

        ✓ Construct a CFG
        ✓ Construct a PDA
        ✓ Use known CFL closure properties

14.39 CHAPTER SUMMARY
======================================================================

The most important concepts from Chapter 14 are:

    1. CFLs are languages generated by CFGs.

    2. Closure means that applying an operation keeps the result
       inside the same language class.

    3. CFLs ARE closed under:

           Union
           Concatenation
           Kleene Star
           Kleene Plus
           Reversal
           Homomorphism
           Inverse Homomorphism

    4. CFLs are NOT generally closed under:

           Intersection
           Complement
           Difference

    5. CFL pumping lemma uses:

           w = uvxyz

    6. The pumpable parts are:

           v and y

    7. Pumped form:

           uvⁱxyⁱz

    8. Important conditions:

           |vxy| ≤ p
           |vy| > 0
           uvⁱxyⁱz ∈ L

    9. Pumping lemma is mainly used to prove:

           "L is NOT CFL."

   10. Classic example:

           {aⁿbⁿcⁿ | n ≥ 0}

       is NOT CFL.

   11. Palindromes over a finite alphabet can be CFL.

   12. Ogden's Lemma is a stronger technique involving marked
       positions.
