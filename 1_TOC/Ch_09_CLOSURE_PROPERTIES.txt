1. CHAPTER INTRODUCTION
======================================================================

Before learning closure properties, remember:

A LANGUAGE is simply a set of strings.

For example, over alphabet Σ = {0,1},

L = {0, 1, 00, 01, 10, 11, ...}

A language is called REGULAR if some finite automaton (DFA/NFA/ε-NFA)
can recognize it.

The important question in this chapter is:

    "If I already have regular languages, and I perform operations
     on them, will the resulting language still be regular?"

For example:

    L1 = strings ending in 0
    L2 = strings containing at least one 1

What happens if we calculate:

    L1 ∪ L2
    L1 ∩ L2
    L1 - L2
    complement(L1)

Will these new languages still be regular?

For regular languages, the answer is YES for all operations covered
in this chapter.


======================================================================
2. WHAT DOES "CLOSED UNDER" MEAN?
======================================================================

Simple meaning:

A collection is CLOSED under an operation if performing that operation
on members of the collection produces another member of the same
collection.

In TOC:

"Regular languages are closed under UNION"

means:

    If L1 and L2 are regular,
    then L1 ∪ L2 is also regular.

Formally:

    If L1 ∈ REG and L2 ∈ REG,

    then:

    L1 ∪ L2 ∈ REG


IMPORTANT:

Closure does NOT mean that every possible language is regular.

It means:

    REGULAR + allowed operation + REGULAR
                         ↓
                    REGULAR


======================================================================
3. WHY DO WE STUDY CLOSURE PROPERTIES?
======================================================================

Closure properties are useful because they allow us to prove that
new languages are regular without constructing a completely new DFA
from scratch.

Suppose:

    L1 is regular
    L2 is regular

If we want to prove:

    L1 ∪ L2

is regular, we can use the closure theorem.

This is often much easier than constructing a machine manually.

Closure properties are important for:

    • B.Tech examinations
    • DFA/NFA theory
    • Regular-language proofs
    • GATE
    • Competitive examinations
    • Formal-language reasoning


======================================================================
4. UNION
======================================================================

4.1 SIMPLE DEFINITION
---------------------

The UNION of two languages contains every string that belongs to
at least one of them.

Notation:

    L1 ∪ L2

Read as:

    "L1 union L2"


4.2 SET DEFINITION
------------------

    L1 ∪ L2 = {w | w ∈ L1 OR w ∈ L2}


4.3 EXAMPLE
------------

Let:

    L1 = {a, ab, aaa}
    L2 = {b, ab, bb}

Then:

    L1 ∪ L2 = {a, ab, aaa, b, bb}

Notice that "ab" occurs only once.


4.4 REGULAR LANGUAGE PROPERTY
-----------------------------

If:

    L1 is regular
    L2 is regular

then:

    L1 ∪ L2 is regular.


4.5 DFA IDEA
------------

Suppose DFA M1 recognizes L1:

                 M1
    input ──────> [DFA 1]

and DFA M2 recognizes L2:

                 M2
    input ──────> [DFA 2]

For union, we can simulate both machines simultaneously.

The combined machine accepts if:

    M1 accepts OR M2 accepts.


======================================================================
5. INTERSECTION
======================================================================

5.1 SIMPLE DEFINITION
---------------------

Intersection contains only strings that belong to BOTH languages.

Notation:

    L1 ∩ L2

Formal definition:

    L1 ∩ L2 = {w | w ∈ L1 AND w ∈ L2}


5.2 EXAMPLE
------------

Let:

    L1 = {a, ab, abc, b}
    L2 = {ab, b, bb}

Then:

    L1 ∩ L2 = {ab, b}


5.3 REGULAR LANGUAGE PROPERTY
-----------------------------

If L1 and L2 are regular:

    L1 ∩ L2

is also regular.


5.4 IMPORTANT DFA IDEA
----------------------

The standard method is PRODUCT CONSTRUCTION.

Suppose:

    M1 recognizes L1
    M2 recognizes L2

Create states of the form:

    (q1, q2)

where:

    q1 = current state of M1
    q2 = current state of M2

The combined machine accepts only when:

    q1 is final AND q2 is final.


ASCII IDEA:

                  input
                    |
            +-------+-------+
            |               |
            v               v
          M1                M2
            |               |
            +-------+-------+
                    |
              BOTH ACCEPT?
                    |
                   YES
                    |
                 ACCEPT


======================================================================
6. COMPLEMENT
======================================================================

6.1 SIMPLE DEFINITION
---------------------

The complement of a language contains all strings over the alphabet
that are NOT in the language.

If:

    Σ = {0,1}

and:

    L = strings ending in 1

then:

    Lᶜ = strings over {0,1} that do NOT end in 1.


6.2 FORMAL DEFINITION
---------------------

The complement is:

    Lᶜ = Σ* - L

Here:

    Σ* = all possible finite strings over Σ.


6.3 EXAMPLE
------------

Let:

    Σ = {0,1}

    L = {strings ending in 1}

Then:

    Lᶜ = {strings ending in 0} ∪ {ε}


Why ε?

Because ε does not end in 1.


6.4 DFA COMPLEMENT
------------------

This is extremely important.

If a DFA is COMPLETE, we can obtain its complement by:

    • Keeping all states
    • Keeping all transitions
    • Changing final states into non-final states
    • Changing non-final states into final states


Original:

    q0 ----0----> q1*
    
    q1* = accepting


Complement:

    q0* ----0----> q1

The accepting status is reversed.


IMPORTANT WARNING:
------------------

This simple state-swapping method requires a COMPLETE DFA.

Every state must have a transition for every symbol.

If a transition is missing, first add a dead/trap state.


======================================================================
7. DIFFERENCE
======================================================================

7.1 SIMPLE DEFINITION
---------------------

The difference between L1 and L2 contains strings that are:

    in L1

but:

    NOT in L2.


7.2 NOTATION
------------

    L1 - L2

or:

    L1 \ L2


7.3 FORMAL DEFINITION
---------------------

    L1 - L2 = {w | w ∈ L1 AND w ∉ L2}


7.4 EXAMPLE
------------

Let:

    L1 = {a, ab, abc, b}
    L2 = {ab, b}

Then:

    L1 - L2 = {a, abc}


7.5 IMPORTANT RELATION
----------------------

Difference can be expressed using intersection and complement:

    L1 - L2 = L1 ∩ L2ᶜ


Since regular languages are closed under:

    • Complement
    • Intersection

regular languages are also closed under difference.


======================================================================
8. CONCATENATION
======================================================================

8.1 SIMPLE DEFINITION
---------------------

Concatenation means joining strings together.

For example:

    x = ab
    y = 101

Then:

    xy = ab101


8.2 LANGUAGE CONCATENATION
--------------------------

For languages L1 and L2:

    L1L2 = {xy | x ∈ L1 and y ∈ L2}


8.3 EXAMPLE
------------

Let:

    L1 = {a, b}
    L2 = {0, 1}

Then:

    L1L2 = {a0, a1, b0, b1}


8.4 REGULARITY
--------------

If:

    L1 is regular
    L2 is regular

then:

    L1L2 is regular.


8.5 NFA IDEA
------------

Concatenation is particularly easy with an NFA.

Suppose:

    NFA 1 accepts L1
    NFA 2 accepts L2

Connect the final states of NFA 1 to the start state of NFA 2
using ε-transitions.

ASCII:

    NFA 1                    NFA 2

   --> q0 ---> q1*   ε   ---> p0 ---> p1*
                  \______________/

The machine first processes a string belonging to L1 and then
processes a string belonging to L2.


======================================================================
9. KLEENE STAR
======================================================================

9.1 SIMPLE DEFINITION
---------------------

Kleene Star means:

    "zero or more repetitions"


Notation:

    L*

If L is a language, L* contains strings formed by concatenating
zero or more strings from L.


9.2 FORMAL DEFINITION
---------------------

    L* = L⁰ ∪ L¹ ∪ L² ∪ L³ ∪ ...

where:

    L⁰ = {ε}


9.3 EXAMPLE
------------

Let:

    L = {a}

Then:

    L* = {ε, a, aa, aaa, aaaa, ...}


Another example:

    L = {ab}

Then:

    L* = {ε, ab, abab, ababab, ...}


9.4 IMPORTANT POINT
-------------------

Kleene Star ALWAYS includes ε.

This is a very common exam trap.


======================================================================
10. KLEENE PLUS
======================================================================

10.1 SIMPLE DEFINITION
----------------------

Kleene Plus means:

    "one or more repetitions"


Notation:

    L+


10.2 FORMAL DEFINITION
----------------------

    L+ = L¹ ∪ L² ∪ L³ ∪ ...


10.3 EXAMPLE
------------

If:

    L = {a}

then:

    L+ = {a, aa, aaa, aaaa, ...}


10.4 STAR VS PLUS
-----------------

                 STAR (*)       PLUS (+)

Repetitions      0 or more       1 or more

Contains ε?      YES             Not necessarily

Example L={a}:
                 {ε,a,aa,...}    {a,aa,aaa,...}


10.5 IMPORTANT RELATION
-----------------------

    L+ = LL*

and:

    L* = {ε} ∪ L+


======================================================================
11. REVERSAL
======================================================================

11.1 STRING REVERSAL
--------------------

Reverse a string by reading it from right to left.

Example:

    w = abc

then:

    wᴿ = cba


Another:

    10110

becomes:

    01101


11.2 LANGUAGE REVERSAL
----------------------

For language L:

    Lᴿ = {wᴿ | w ∈ L}


11.3 EXAMPLE
------------

Let:

    L = {ab, abc, 10}

Then:

    Lᴿ = {ba, cba, 01}


11.4 REGULARITY
---------------

If L is regular, then:

    Lᴿ

is also regular.


11.5 NFA IDEA
-------------

Take an NFA for L.

To construct an automaton for Lᴿ:

    • Reverse every transition
    • Make the old final states new starting possibilities
    • Make the old start state the new final state

Because there may be multiple old final states, an ε-NFA can be used
with a new start state.


ASCII:

Original:

    --> q0 ----a----> q1 ----b----> q2*

Reversed idea:

    --> q2 ----b----> q1 ----a----> q0*

If there are multiple final states, connect a new start state to all
of them using ε-transitions.


======================================================================
12. HOMOMORPHISM
======================================================================

This is a more advanced topic, so understand the intuition first.


12.1 SIMPLE IDEA
----------------

A homomorphism is a systematic replacement of symbols.

For example:

    h(0) = a
    h(1) = bb

Then:

    h(01) = h(0)h(1)
          = a bb
          = abb


12.2 FORMAL DEFINITION
----------------------

A homomorphism h maps symbols from one alphabet to strings over
another alphabet.

If:

    h : Σ → Γ*

then for a string:

    w = a1a2...an

we define:

    h(w) = h(a1)h(a2)...h(an)


12.3 EXAMPLE
------------

Let:

    h(0) = x
    h(1) = yz

Then:

    h(001)

= h(0)h(0)h(1)

= x x yz

= xxyz


12.4 LANGUAGE HOMOMORPHISM
--------------------------

For language L:

    h(L) = {h(w) | w ∈ L}


12.5 CLOSURE PROPERTY
---------------------

If L is regular, then:

    h(L)

is also regular.


======================================================================
13. INVERSE HOMOMORPHISM
======================================================================

This is the reverse-direction concept.

Instead of applying h to strings in L, we ask:

    "Which strings are mapped by h INTO L?"


13.1 FORMAL DEFINITION
----------------------

For language L over Γ:

    h⁻¹(L) = {w ∈ Σ* | h(w) ∈ L}


13.2 SIMPLE EXAMPLE
-------------------

Suppose:

    h(0) = a
    h(1) = b

and:

    L = {strings ending in a}

Then:

    h⁻¹(L)

contains binary strings that, after replacing:

    0 → a
    1 → b

produce strings ending in a.

Therefore:

    h⁻¹(L) = strings ending in 0.


13.3 CLOSURE PROPERTY
---------------------

If L is regular, then:

    h⁻¹(L)

is also regular.

15. PRODUCT CONSTRUCTION
======================================================================

Product construction is one of the most important ideas in this
chapter and is frequently useful in GATE questions.


15.1 BASIC IDEA
---------------

Suppose:

    M1 = DFA for L1
    M2 = DFA for L2

We construct a new DFA whose states are PAIRS:

    (q1, q2)


If:

    M1 has m states
    M2 has n states

then the product DFA has at most:

    m × n

states.


15.2 EXAMPLE
------------

Suppose M1 has:

    Q1 = {A, B}

and M2 has:

    Q2 = {X, Y}

Then product states are:

    (A,X)
    (A,Y)
    (B,X)
    (B,Y)


ASCII:

                  M2 states

                X          Y
             +----------+----------+
        A    |  (A,X)   |  (A,Y)   |
             +----------+----------+
        B    |  (B,X)   |  (B,Y)   |
             +----------+----------+


15.3 TRANSITION
---------------

If:

    δ1(q1,a) = p1

and:

    δ2(q2,a) = p2

then product transition is:

    δ((q1,q2),a) = (p1,p2)


In simple words:

    Read the same input symbol in both machines
    and record both resulting states.


======================================================================
16. PRODUCT CONSTRUCTION FOR INTERSECTION
======================================================================

For:

    L1 ∩ L2

the product DFA accepts when BOTH machines are in final states.

If:

    F1 = final states of M1
    F2 = final states of M2

then:

    F = F1 × F2


That means:

    (q1,q2) is final
    iff
    q1 ∈ F1 AND q2 ∈ F2


ASCII:

       M1                         M2
       |                          |
       v                          v
   current q1                current q2
       |                          |
       +------------+-------------+
                    |
                    v
                 (q1,q2)
                    |
            BOTH final?
               /       \
             YES        NO
              |          |
           ACCEPT      REJECT


======================================================================
17. PRODUCT CONSTRUCTION FOR UNION
======================================================================

For:

    L1 ∪ L2

the product DFA accepts when AT LEAST ONE machine is in a final state.

Therefore:

    (q1,q2) is final

if:

    q1 ∈ F1 OR q2 ∈ F2


Truth table:

    M1       M2       UNION
    --------------------------------
    No       No       No
    No       Yes      Yes
    Yes      No       Yes
    Yes      Yes      Yes


Compare with intersection:

    M1       M2       INTERSECTION
    --------------------------------
    No       No       No
    No       Yes      No
    Yes      No       No
    Yes      Yes      Yes


======================================================================
18. PRODUCT CONSTRUCTION — GENERAL IDEA
======================================================================

The product construction is closely related to Boolean logic.

For each pair of states:

    (q1,q2)

we remember the state of both machines.

Then we decide whether the pair is accepting according to the
required operation.

Examples:

    UNION:
        q1 final OR q2 final

    INTERSECTION:
        q1 final AND q2 final

    DIFFERENCE:
        q1 final AND q2 not final


This is extremely useful in exam problems.


======================================================================
19. CLOSURE USING REGULAR EXPRESSIONS
======================================================================

Another way to understand closure is through regular expressions.

Regular expressions are built from operations such as:

    • Union
    • Concatenation
    • Kleene Star

Therefore, if:

    R1

and:

    R2

are regular expressions, then:

    R1 | R2

is also a regular expression.

Likewise:

    R1R2

and:

    R1*

are regular expressions.

Hence the languages represented by them are regular.


Example:

    R1 = 0*
    R2 = 1*

Then:

    R1R2 = 0*1*

represents:

    {0^i 1^j | i,j >= 0}

which is regular.


======================================================================
20. CLOSURE USING NFA
======================================================================

NFAs are especially convenient for several constructions.

UNION:

    Create a new start state.

    From new start:
          ε → NFA1
          ε → NFA2

ASCII:

                  ε ---> NFA1
                 /
        new q0 --
                 \
                  ε ---> NFA2


CONCATENATION:

    Connect final states of NFA1 to start of NFA2 using ε.


KLEENE STAR:

    Add a new start/final state and ε-transitions that allow the
    machine to repeat the original NFA zero or more times.


REVERSAL:

    Reverse transitions and use a new start state if necessary.


======================================================================
21. IMPORTANT THEOREM
======================================================================

THEOREM:

    The class of regular languages is closed under:

    • Union
    • Intersection
    • Complement
    • Difference
    • Concatenation
    • Kleene Star
    • Kleene Plus
    • Reversal
    • Homomorphism
    • Inverse Homomorphism


Meaning:

    Starting with regular languages and applying any of these
    operations produces another regular language.


======================================================================
22. HOW TO SOLVE CLOSURE QUESTIONS
======================================================================

When you see:

    "L1 and L2 are regular. Prove that ______ is regular."

Use this strategy:

STEP 1:
    Identify the operation.

STEP 2:
    Recall the closure property.

STEP 3:
    State that L1 and L2 are regular.

STEP 4:
    Apply the appropriate closure theorem.

STEP 5:
    Conclude that the resulting language is regular.


Example:

    Given:
        L1 is regular
        L2 is regular

    Prove:
        L1 - L2 is regular.


Solution:

    L1 - L2 = L1 ∩ L2ᶜ

    Since L2 is regular:
        L2ᶜ is regular.

    Since regular languages are closed under intersection:
        L1 ∩ L2ᶜ is regular.

    Therefore:
        L1 - L2 is regular.


======================================================================
23. IMPORTANT EXAM DISTINCTIONS
======================================================================

UNION vs INTERSECTION
---------------------

Union:
    At least one language contains the string.

Intersection:
    Both languages contain the string.


STAR vs PLUS
------------

L*:
    zero or more repetitions.

L+:
    one or more repetitions.


COMPLEMENT vs DIFFERENCE
------------------------

Complement:

    Lᶜ = Σ* - L

Difference:

    L1 - L2 = L1 ∩ L2ᶜ


HOMOMORPHISM vs INVERSE HOMOMORPHISM
------------------------------------

Homomorphism:

    Start with a string w
    ↓
    Apply h
    ↓
    h(w)


Inverse homomorphism:

    Start with language L
    ↓
    Find all w such that h(w) ∈ L

24. COMMON MISTAKES
======================================================================

MISTAKE 1:
    Thinking "closed" means every language is regular.

CORRECT:
    Only when the input languages are already regular.


MISTAKE 2:
    Forgetting ε in L*.

CORRECT:
    L* always contains ε.


MISTAKE 3:
    Thinking L+ always contains ε.

CORRECT:
    Not necessarily.


MISTAKE 4:
    Using DFA state swapping for complement when the DFA is incomplete.

CORRECT:
    Complete the DFA first.


MISTAKE 5:
    Confusing:

        L1 - L2

    with:

        L2 - L1

They are generally different.


MISTAKE 6:
    For intersection, accepting if either DFA accepts.

CORRECT:
    Both must accept.


MISTAKE 7:
    For union, requiring both DFAs to accept.

CORRECT:
    At least one must accept.

        = L⁰ ∪ L¹ ∪ L² ∪ ...

    L+
        = L¹ ∪ L² ∪ L³ ∪ ...

    L+
        = LL*

    L*
        = {ε} ∪ L+
