                         CHAPTER 7 — OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Chapter 6 taught us:

    DFA
    NFA
    ε-NFA
    ε-closure
    Subset construction
    NFA → DFA
    DFA minimization


Chapter 7 connects TWO major representations of regular languages:


                  REGULAR EXPRESSION
                         ↕
                    FINITE AUTOMATA


The major transformations are:


    REGULAR EXPRESSION
            │
            ▼
        ε-NFA
            │
            ▼
          DFA
            │
            ▼
      MINIMAL DFA


And in the opposite direction:


          DFA
           │
           ▼
    REGULAR EXPRESSION


Therefore:


        REGULAR EXPRESSION  ⇄  FINITE AUTOMATA


This equivalence is one of the foundations of lexical analysis.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. WHAT IS THE MAIN IDEA?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A regular expression is a mathematical notation for describing a
regular language.

A finite automaton is a machine for recognizing that language.


So:


        REGULAR EXPRESSION
        "What strings are allowed?"
                  │
                  ▼
        FINITE AUTOMATON
        "How can I recognize them?"


Example:


    Regular expression:


        (0|1)*01


describes all binary strings ending in:


        01


A finite automaton can recognize exactly the same language.


Therefore the two are equivalent representations.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. REGULAR LANGUAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DEFINITION:

A language is called regular if it can be described by a regular
expression or recognized by a finite automaton.


Therefore:


        L is REGULAR
              ⇕
        L has a REGULAR EXPRESSION
              ⇕
        L is recognized by a DFA
              ⇕
        L is recognized by an NFA
              ⇕
        L is recognized by an ε-NFA


This equivalence is extremely important.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. THE BIG EQUIVALENCE THEOREM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


                     REGULAR LANGUAGES
                            │
              ┌─────────────┼─────────────┐
              │             │             │
              ▼             ▼             ▼
             RE            NFA           DFA
              │             │             │
              └─────────────┼─────────────┘
                            │
                            ▼
                     SAME EXPRESSIVE
                         POWER


IMPORTANT:

    DFA is not more powerful than NFA.

    NFA is not more powerful than RE.

    RE, NFA and DFA all describe/recognize REGULAR LANGUAGES.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. TRANSFORMATION PIPELINE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


                     REGULAR EXPRESSION
                              │
                              │ Thompson's
                              │ Construction
                              ▼
                            ε-NFA
                              │
                              │ ε-closure
                              │ + subset construction
                              ▼
                             DFA
                              │
                              │ minimization
                              ▼
                        MINIMAL DFA


Reverse direction:


                        DFA / NFA
                           │
                           ▼
                  REGULAR EXPRESSION


There are multiple methods for DFA → RE, including:

    • State elimination
    • Arden's theorem
    • GNFA-based conversion


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. RE → NFA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The standard construction is:


        THOMPSON'S CONSTRUCTION


It converts a regular expression into an equivalent ε-NFA.


Pipeline:


        RE
        │
        ▼
    Thompson
        │
        ▼
      ε-NFA


The construction works recursively for the basic regular-expression
operations:


    • Symbol
    • ε
    • Empty language
    • Union
    • Concatenation
    • Kleene star


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6. BASIC CONSTRUCTION — SINGLE SYMBOL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

For the regular expression:


        a


construct:


        q0 ──a──► q1


Here:


    q0 = start state

    q1 = final state


The language recognized is:


        {a}


Therefore:


        RE: a


and:


        NFA: q0 --a--> q1


represent the same language.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
7. CONSTRUCTION — ε
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The regular expression:


        ε


accepts the empty string.


Construct:


        q0 ──ε──► q1


The automaton can reach the final state without consuming any input.


Therefore:


        L(ε) = {ε}


Important distinction:


        ε ≠ ∅


ε means:


        empty string


∅ means:


        empty language


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
8. CONSTRUCTION — EMPTY LANGUAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

For:


        ∅


there is no path from start to final state.


Conceptually:


        q0              q1
        ○               ◎


No transition connects them.


Therefore:


        L(∅) = ∅


No input string is accepted.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
9. CONSTRUCTION — UNION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Suppose:


        R = A | B


This means:


        either A OR B


Create a new start and final state:


                         ε ──► NFA(A) ──ε──┐
                        /                    │
              START ───                      ├──► FINAL
                        \                    │
                         ε ──► NFA(B) ──ε──┘


The new start can choose either branch.


Therefore:


        L(A|B) = L(A) ∪ L(B)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
10. UNION EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Expression:


        a | b


Construction:


                         ε ──► q1 ──a──► q2 ──ε──┐
                        /                         │
              → q0 ────                           ──► q5
                        \                         │
                         ε ──► q3 ──b──► q4 ──ε──┘


Accepted strings:


        a
        b


Therefore:


        L(a|b) = {a,b}


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
11. CONSTRUCTION — CONCATENATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Suppose:


        R = AB


This means:


        first recognize A,
        then recognize B.


Conceptually:


        NFA(A) ─────► NFA(B)


If:


        A = a
        B = b


then:


        ab


becomes:


        q0 ──a──► q1 ──b──► q2


Accepted string:


        ab


Therefore:


        L(AB) = L(A)L(B)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
12. CONCATENATION EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Expression:


        (a|b)c


First construct:


        a|b


Then concatenate:


        c


Conceptually:


              ┌──a──►
        START│
              └──b──►
                    │
                    ▼
                    c
                    │
                    ▼
                  FINAL


Accepted strings:


        ac
        bc


Therefore:


        L((a|b)c) = {ac,bc}


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
13. CONSTRUCTION — KLEENE STAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

For:


        A*


we need:


        zero or more repetitions of A.


Thompson construction:


                         ε
                    ┌───────────┐
                    │           ▼
                 START ─ε──► NFA(A) ──ε──► FINAL
                    │           ▲
                    │           │
                    └─────ε─────┘


The two important possibilities are:


    START ──ε──► FINAL


meaning:


    zero repetitions


and:


    NFA(A) ──ε──► NFA(A)


meaning:


    repeat A.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
14. KLEENE STAR EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Expression:


        a*


Language:


        {ε, a, aa, aaa, aaaa, ...}


The automaton can accept:


        ε
        a
        aa
        aaa
        ...


Therefore:


        L(a*) = {a^n | n ≥ 0}


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
15. THOMPSON'S CONSTRUCTION — RECURSIVE IDEA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Complex regular expressions are broken into smaller expressions.


Example:


        (a|b)*c


Break it down:


        (a|b)*c
            │
        ┌───┴────┐
        │        │
      (a|b)*     c
        │
        ▼
       a|b
       / \
      a   b


Then construct an ε-NFA for each piece and connect them.


Therefore:


        COMPLEX RE
             ↓
        BREAK INTO PARTS
             ↓
        BUILD SMALL NFAs
             ↓
        CONNECT WITH ε
             ↓
          ε-NFA


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
16. RE → ε-NFA COMPLETE PROCESS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


    REGULAR EXPRESSION
            │
            ▼
    Identify operators
            │
            ├── symbol
            ├── union
            ├── concatenation
            └── star
            │
            ▼
    Build elementary NFAs
            │
            ▼
    Combine recursively
            │
            ▼
          ε-NFA


Important property:


    The resulting ε-NFA has exactly one start state
    and one accepting state in the standard Thompson construction.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
17. NFA → DFA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Once we have an ε-NFA, we can convert it to a DFA using:


        SUBSET CONSTRUCTION


Pipeline:


        ε-NFA
          │
          ▼
    ε-closure(start)
          │
          ▼
    Create DFA state
          │
          ▼
    For each input symbol:
          │
          ▼
    move + ε-closure
          │
          ▼
    Create new DFA states
          │
          ▼
       Continue
          │
          ▼
          DFA


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
18. SUBSET CONSTRUCTION — KEY FORMULA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

For DFA state S and input symbol a:


        δD(S,a)
        =
        ε-closure(move(S,a))


Remember the order:


        1. MOVE
             ↓
        2. ε-CLOSURE


The initial DFA state is:


        ε-closure({q0})


where q0 is the NFA start state.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
19. ACCEPTING DFA STATES AFTER CONVERSION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Suppose the NFA has final state:


        qf


During subset construction, any DFA state containing qf is accepting.


Example:


        DFA state = {q1,q3,qf}


Since it contains qf:


        ACCEPTING DFA STATE


Therefore:


        DFA final states
        =
        subsets containing an NFA final state


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
20. RE → DFA COMPLETE PIPELINE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


        REGULAR EXPRESSION
                │
                ▼
        THOMPSON CONSTRUCTION
                │
                ▼
              ε-NFA
                │
                ▼
        SUBSET CONSTRUCTION
                │
                ▼
               DFA
                │
                ▼
        DFA MINIMIZATION
                │
                ▼
          MINIMAL DFA


This pipeline is fundamental in lexical analyzer implementation.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
21. DFA → REGULAR EXPRESSION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Now the reverse direction.


Given:


        DFA


we want:


        REGULAR EXPRESSION


There are several approaches.


Most important:


    1. State elimination
    2. Arden's theorem
    3. GNFA method


The most intuitive method for beginners is:


        STATE ELIMINATION


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
22. STATE ELIMINATION — BASIC IDEA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

We start with an automaton:


        START
          │
          ▼
         q0
          │
          ▼
         q1
          │
          ▼
        FINAL


We progressively remove intermediate states while preserving the
language recognized by the automaton.


Eventually:


        START ──REGULAR EXPRESSION──► FINAL


The label on the final edge is the required regular expression.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
23. WHY CAN STATES BE ELIMINATED?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Suppose:


        q1 ──A──► q2
        q2 ──B──► q3


If q2 is removed:


        q1 ──AB──► q3


because reaching q3 through q2 means:


        A followed by B


Therefore:


        A + B transitions
        ↓
        concatenation


        A followed by B
        ↓
        AB


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
24. ELIMINATION WITH ALTERNATIVE PATHS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Suppose:


        q1 ──A──► q2
        q1 ──B──► q2


Both paths go from q1 to q2.


They can be combined into:


        q1 ──(A|B)──► q2


because either A or B can be used.


Therefore:


        multiple parallel paths
                 ↓
              UNION
                 ↓
              A | B


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
25. ELIMINATION WITH A LOOP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Suppose q2 has a self-loop:


        q2 ──R──► q2


and:


        q1 ──A──► q2
        q2 ──B──► q3


To pass through q2:


        A
        followed by
        zero or more R
        followed by
        B


Therefore:


        A R* B


So after eliminating q2:


        q1 ──AR*B──► q3


This is the key idea behind state elimination.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
26. GENERAL STATE-ELIMINATION FORMULA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Suppose we eliminate state:


        qk


There is:


    Rij
        = expression from qi to qj


    Rik
        = expression from qi to qk


    Rkk
        = loop on qk


    Rkj
        = expression from qk to qj


After eliminating qk:


        Rij(new)
        =
        Rij
        |
        Rik (Rkk)* Rkj


In words:


    old direct path

        OR

    path entering qk
    +
    zero or more loops at qk
    +
    path leaving qk


This formula is extremely important for advanced problems.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
27. GENERAL STATE-ELIMINATION DIAGRAM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


                Rik
        qi ─────────────► qk
        │                 │
        │                 │ Rkk
        │                 ↺
        │                 │
        │                 │ Rkj
        │                 ▼
        └───────────────► qj
              Rij


After removing qk:


        qi ──[ Rij | Rik(Rkk)*Rkj ]──► qj


This preserves the language.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
28. DFA → RE USING GNFA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

GNFA means:


        GENERALIZED NONDETERMINISTIC FINITE AUTOMATON


Instead of transitions being labeled only with individual symbols,
they can be labeled with regular expressions.


Example:


        q1 ──(a|b)*──► q2


The transition label itself is a regular expression.


This makes state elimination easier.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
29. GNFA CONVERSION — BASIC STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

To convert a DFA to a regular expression using GNFA:


    STEP 1:
        Create a new unique start state.


    STEP 2:
        Add ε-transition from new start to old start.


    STEP 3:
        Create a new unique final state.


    STEP 4:
        Add ε-transitions from every old final state
        to the new final state.


    STEP 5:
        Combine parallel edges using |.


    STEP 6:
        Eliminate intermediate states.


    STEP 7:
        Continue until only start and final remain.


    STEP 8:
        The remaining edge label is the regular expression.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
30. ARDEN'S THEOREM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Another important method for converting finite automata to regular
expressions uses:


        ARDEN'S THEOREM


Arden's theorem is based on language equations.


The standard form is:


        X = Q + XP


If:


        ε ∉ P


then the unique solution is:


        X = QP*


An equivalent commonly used form is:


        X = Q + PX


with solution:


        X = P*Q


under the corresponding condition that ε is not in P.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
31. UNDERSTANDING ARDEN'S THEOREM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Suppose:


        X = A + XB


This means:


        X
        =
        A
        OR
        X followed by B


Repeated substitution gives:


        X = A + XB


        X = A + (A + XB)B


        X = A + AB + XBB


        X = A + AB + ABB + XBBB


Continuing:


        X = A + AB + ABB + ABBB + ...


Therefore:


        X = AB*


provided the theorem's condition holds.


This is the mathematical reason behind the star operation.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
32. DFA → RE USING ARDEN'S THEOREM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Basic strategy:


    1. Assign a variable to each state.


    2. Write equations describing incoming transitions.


    3. Apply Arden's theorem.


    4. Solve the equations.


    5. Expression associated with the final state gives
       the regular expression.


Example structure:


        X0 = ε + X0a + X1b


        X1 = X0c


Then solve the system algebraically.


This approach is especially useful in theory and exam questions.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
33. DFA → RE EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Consider:


        → q0 ──a──► q1
          ▲         │
          │         │ b
          └─────────┘


Suppose q1 is final.


The machine accepts:


        a
        ab
        abb
        abbb
        ...


Therefore:


        L = ab*


So the equivalent regular expression is:


        ab*


This illustrates the idea of converting automaton behavior into a
regular expression.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
34. DFA → RE: ANOTHER SIMPLE EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Automaton:


        → q0 ──a──► ◎q1
                     │
                     │ a
                     ▼
                    q1


The accepted strings are:


        a
        aa
        aaa
        aaaa
        ...


Therefore:


        L = aa*


Equivalent forms:


        aa*


or:


        a+a


if positive closure notation is available.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
35. REGULAR EXPRESSION TO DFA — DIRECT CONCEPT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

There are several ways to go from RE to DFA.


Most common theoretical pipeline:


        RE
        ↓
        ε-NFA
        ↓
        DFA


Why not directly?


Because Thompson's construction gives a systematic way to construct
an ε-NFA from every regular expression.


Then subset construction gives the DFA.


Therefore:


        RE → ε-NFA → DFA


is the standard approach.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
36. DIRECT RE → DFA — OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

There are also direct methods, such as the:


        POSITIONAL / SYNTAX-TREE METHOD


One well-known approach uses:


        followpos


along with:


        nullable
        firstpos
        lastpos


This can construct a DFA directly from a regular expression without
first explicitly constructing an NFA.


This is an advanced topic used in lexer theory.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
37. SYNTAX TREE METHOD — IDEA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Suppose the regular expression is:


        (a|b)*abb


A syntax tree represents the structure of the expression.


Conceptually:


                         .
                       /   \
                      *     .
                     /     / \
                    |     a   .
                   / \       / \
                  a   b     b   b


The exact tree depends on explicit concatenation operators.


The tree is then annotated using:


    nullable
    firstpos
    lastpos
    followpos


to construct the DFA.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
38. NULLABLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

In the syntax-tree method:


        nullable(n)


answers:


    "Can the expression represented by node n
     generate ε?"


Examples:


        nullable(ε) = TRUE


        nullable(a) = FALSE


For union:


        nullable(A|B)
        =
        nullable(A) OR nullable(B)


For concatenation:


        nullable(AB)
        =
        nullable(A) AND nullable(B)


For star:


        nullable(A*)
        =
        TRUE


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
39. FIRSTPOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

firstpos(n) is the set of positions that can appear first in a string
generated by the expression represented by node n.


For a leaf symbol:


        a


with position 1:


        firstpos(a) = {1}


For union:


        firstpos(A|B)
        =
        firstpos(A) ∪ firstpos(B)


For concatenation:


    If A is nullable:

        firstpos(AB)
        =
        firstpos(A) ∪ firstpos(B)


    Otherwise:

        firstpos(AB)
        =
        firstpos(A)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
40. LASTPOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

lastpos(n) is the set of positions that can appear last in a string
generated by the expression represented by node n.


For a leaf:


        lastpos(a) = {position(a)}


For union:


        lastpos(A|B)
        =
        lastpos(A) ∪ lastpos(B)


For concatenation:


    If B is nullable:

        lastpos(AB)
        =
        lastpos(A) ∪ lastpos(B)


    Otherwise:


        lastpos(AB)
        =
        lastpos(B)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
41. FOLLOWPOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

followpos(i) tells us:


    Which positions can immediately follow position i
    in strings generated by the regular expression?


This is the key idea in the direct RE → DFA construction.


For concatenation:


        A · B


every position in:


        lastpos(A)


can be followed by every position in:


        firstpos(B)


Therefore:


        for every i ∈ lastpos(A):

            add firstpos(B) to followpos(i)


For star:


        A*


every position in:


        lastpos(A)


can be followed by every position in:


        firstpos(A)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
42. DIRECT RE → DFA PIPELINE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


                REGULAR EXPRESSION
                        │
                        ▼
                   Syntax Tree
                        │
            ┌───────────┼───────────┐
            ▼           ▼           ▼
         nullable    firstpos    lastpos
                        │
                        ▼
                    followpos
                        │
                        ▼
                   DFA STATES
                        │
                        ▼
                       DFA


This is an advanced but important compiler-design technique.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
43. APPLICATION IN LEXICAL ANALYSIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Lexical analyzers often specify token patterns using regular
expressions.


Example:


        Identifier:


        letter(letter|digit)*


        Integer:


        digit+


        Whitespace:


        (space|tab|newline)+


These regular expressions can be converted into automata.


Pipeline:


    TOKEN DEFINITIONS
          │
          ▼
    REGULAR EXPRESSIONS
          │
          ▼
        ε-NFA
          │
          ▼
         DFA
          │
          ▼
    DFA MINIMIZATION
          │
          ▼
      LEXICAL ANALYZER
          │
          ▼
         TOKENS


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
44. MULTIPLE TOKEN REGULAR EXPRESSIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A real lexer usually recognizes many token types.


For example:


        ID       → letter(letter|digit)*
        NUMBER   → digit+
        PLUS     → +
        MINUS    → -
        EQ       → =
        LE       → <=


The lexer can combine these patterns into an automaton.


Conceptually:


                      ┌──► ID
                      │
                      ├──► NUMBER
        INPUT ────────┼──► PLUS
                      │
                      ├──► MINUS
                      │
                      └──► OPERATOR


The automaton determines which token pattern matches.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
45. PRIORITY RULES IN LEXICAL ANALYSIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Sometimes multiple token patterns can match the same input.


For example:


        "="


might match:


        ASSIGN


while:


        "=="


matches:


        EQUAL_EQUAL


The lexer needs rules to resolve such situations.


Common principles include:


    1. Longest match


    2. Rule priority / earlier rule priority


This is why converting regexes to automata is not the entire lexer
design.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

48. IMPORTANT PROPERTIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROPERTY 1:

    Every regular expression can be converted to an equivalent
    finite automaton.


PROPERTY 2:

    Every finite automaton can be converted to an equivalent
    regular expression.


PROPERTY 3:

    Every NFA can be converted to an equivalent DFA.


PROPERTY 4:

    Every DFA can be minimized.


PROPERTY 5:

    DFA, NFA, ε-NFA and regular expressions have the same
    expressive power over regular languages.

49. COMMON CONFUSIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CONFUSION 1:

    NFA is more powerful than DFA.

WRONG.

    Both recognize exactly the regular languages.


CONFUSION 2:

    ε means empty language.

WRONG.

    ε = empty string

    ∅ = empty language


CONFUSION 3:

    DFA can have multiple transitions on the same symbol.

WRONG.

    For each state and input symbol, DFA has exactly one destination.


CONFUSION 4:

    NFA must choose only one path.

WRONG.

    Multiple paths may exist; acceptance requires at least one
    successful path.


CONFUSION 5:

    Every possible subset of NFA states necessarily appears in
    the converted DFA.

WRONG.

    Only REACHABLE subsets are constructed in normal subset
    construction.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
50. EXAM-IMPORTANT FORMULAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


    DFA:


        δ : Q × Σ → Q


    NFA:


        δ : Q × Σ → 2^Q


    ε-NFA:


        δ : Q × (Σ ∪ {ε}) → 2^Q


    ε-closure:


        ε-closure(q)
        =
        all states reachable from q using
        zero or more ε-transitions


    Subset construction:


        δD(S,a)
        =
        ε-closure(move(S,a))


    Maximum number of DFA states from n-state NFA:


        2^n


    Arden's theorem:


        X = Q + XP

        ⇒ X = QP*

        if ε ∉ P


    Equivalent alternate form:


        X = Q + PX

        ⇒ X = P*Q

        if ε ∉ P
