CHAPTER 0.4 — THEORY OF COMPUTATION BASICS
============================================================

0.4.1 Alphabet
------------------------------------------------------------
An alphabet is a finite set of symbols.

Notation:

    Σ

Example:

    Σ = {0, 1}

Another example:

    Σ = {a, b, c}


0.4.2 Strings
------------------------------------------------------------
A string is a finite sequence of symbols from an alphabet.

Example:

    Σ = {0,1}

Possible strings:

    0
    1
    01
    10
    101
    1101

Important concepts:

    • Length of string
    • Empty string
    • String concatenation
    • Prefix
    • Suffix
    • Substring

Empty string:

    ε

Length:

    |w|

Example:

    w = 1011

    |w| = 4


0.4.3 Languages
------------------------------------------------------------
A language is a set of strings over an alphabet.

If:

    Σ = {0,1}

Then:

    L = {0, 1, 01, 10}

is a language over Σ.

Compiler relevance:

    Programming language
          ↓
    Set of valid programs
          ↓
    Language

0.4.7 Context-Free Grammars
------------------------------------------------------------
• What is a grammar?
• Terminals
• Non-terminals
• Productions
• Start symbol
• Derivation
• Parse tree

Formal representation:

    G = (V, T, P, S)

where:

    V = set of non-terminals
    T = set of terminals
    P = set of productions
    S = start symbol

Example:

    E → E + T
    E → T
    T → id
