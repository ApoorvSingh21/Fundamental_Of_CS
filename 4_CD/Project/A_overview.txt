This project i'm start building a simple complier using cpp language that
reconize simple language 

let x = 10;
let y = 20;
let z = x + y;

print(z);

phase's 
Stage
Component
What we build
1 Language Design   MiniLang syntax and rules
2 Lexer             C++ lexical analyzer
3 Parser            Recursive-descent parser
4 AST               Abstract Syntax Tree
5 Semantic          Analyzer Types, declarations, scope
6 Symbol Table      Variable management
7 IR                Three-address code
8 Control Flow      if, while
9 Code8 Generation  enerate executable instructions
10 Virtual Machine  Run generated instructions
11 Error Handling   Compiler error messages
12 Testing          Test programs and edge cases
