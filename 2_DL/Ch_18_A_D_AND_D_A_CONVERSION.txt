18.2 ANALOG SIGNAL
============================================================

An ANALOG signal is a signal whose amplitude can take
continuously varying values over a range.


Example:

Voltage may be:

    0.1 V
    0.2 V
    0.25 V
    0.251 V
    0.2517 V
    ...

There can theoretically be infinitely many values
between two points.


ASCII representation:

Voltage
  ^
  |       /‾‾\        /‾‾\
  |      /    \      /    \
  |_____/      \____/      \____> Time


Examples:

    Microphone output
    Temperature sensor
    Light sensor
    Human voice
    ECG signal


============================================================
18.3 DIGITAL SIGNAL
============================================================

A DIGITAL signal uses discrete levels.

For binary logic:

        HIGH → 1
        LOW  → 0


Example:

        __      __
       |  |    |  |
    ___|  |____|  |____
       1   0    1   0


Digital signals do not represent every possible
analog value directly.


============================================================

   +-----+

18.8 SAMPLING
============================================================

Sampling means measuring the amplitude of an analog
signal at discrete time intervals.


Continuous:

    ~~~~~~~~ analog waveform ~~~~~~~~

Sampled:

        •       •       •       •
       /       /       /       /
      /       /       /       /
    --•-------•-------•-------•----> Time


The ADC does not continuously store the entire
analog waveform.

It takes samples at specific times.


============================================================
18.9 SAMPLING RATE
============================================================

Sampling rate is the number of samples taken per second.

Unit:

        Samples/second

Also called:

        Samples per second (S/s)


Example:

        1000 samples/sec

means:

        1000 measurements every second.


If:

        Sampling frequency = 10 kHz

then:

        10,000 samples/sec


============================================================
18.10 QUANTIZATION
============================================================

After sampling, each sampled amplitude must be mapped
to one of a finite number of digital levels.

This process is called:

        QUANTIZATION


Analog amplitude:

        0
        |
        |      •
        |    •
        |  •
        | •
        +---------------- Time


Quantized levels:

        Level 4 ─────────────
        Level 3 ─────────────
        Level 2 ─────────────
        Level 1 ─────────────
        Level 0 ─────────────


A sampled value may not exactly match a level.

It is assigned to the nearest available level
according to the quantizer design.


============================================================
18.11 QUANTIZATION ERROR
============================================================

Because the analog signal can have many possible
values but the ADC has only finite digital levels,
there is usually a difference between:

        Actual analog value

and

        Quantized value


This difference is called:

        QUANTIZATION ERROR


Example:

Actual:

        2.37 V


Quantized:

        2.40 V


Error:

        2.40 - 2.37
        = 0.03 V


Therefore:

        Quantization error = 0.03 V


============================================================
18.12 ENCODING
============================================================

After quantization, each quantization level is assigned
a binary code.


Example:

Level 0 → 000
Level 1 → 001
Level 2 → 010
Level 3 → 011
Level 4 → 100
Level 5 → 101
Level 6 → 110
Level 7 → 111


Thus:

        Quantized level
              |
              v
        Binary code


This process is called:

        ENCODING

============================================================
18.14 ADC RESOLUTION
============================================================

Resolution tells us how finely an ADC can distinguish
different input voltage levels.


For an N-bit ADC:

        Number of levels = 2^N


Examples:

        1-bit → 2 levels
        2-bit → 4 levels
        3-bit → 8 levels
        4-bit → 16 levels
        8-bit → 256 levels
        10-bit → 1024 levels
        12-bit → 4096 levels
        16-bit → 65536 levels


Therefore:

        Higher number of bits
                ↓
        More quantization levels
                ↓
        Finer resolution


============================================================
18.15 RESOLUTION FORMULA
============================================================

For an ideal N-bit ADC with input range:

        0 to Vref


Approximate step size:

        Resolution =
        Vref / 2^N


Some textbooks define the LSB size using
slightly different endpoint conventions.

For most introductory exam problems:

        LSB size ≈ Vref / 2^N


============================================================
18.16 RESOLUTION EXAMPLE
============================================================

Given:

        N = 8 bits
        Vref = 5 V


Number of levels:

        2^8 = 256


Resolution:

        5 / 256
        ≈ 0.01953 V


Therefore:

        ≈ 19.53 mV per LSB


An 8-bit ADC over 0–5 V can therefore
distinguish approximately 19.53 mV steps.


============================================================
18.17 COMPARING ADC RESOLUTION
============================================================

Suppose:

        ADC A = 8-bit
        ADC B = 12-bit


ADC A:

        2^8 = 256 levels


ADC B:

        2^12 = 4096 levels


Therefore ADC B provides:

        4096 / 256
        = 16 times

as many quantization levels.


Hence:

        12-bit ADC has finer resolution
        than an 8-bit ADC.

18.18 DAC BASIC IDEA
============================================================

A DAC performs the reverse operation.

        DIGITAL CODE
             |
             v
          +-----+
          | DAC |
          +-----+
             |
             v
        ANALOG VOLTAGE


For example, for a 3-bit DAC:

        000
        001
        010
        011
        100
        101
        110
        111

represent increasing analog output levels
in an ideal unipolar DAC.


============================================================
18.19 DAC RESOLUTION
============================================================

For an N-bit DAC:

        Number of possible output codes
        =
        2^N


Example:

        8-bit DAC:

        2^8 = 256 levels


12-bit DAC:

        2^12 = 4096 levels


Higher resolution means smaller output
steps between adjacent codes.


============================================================
18.20 DAC STEP SIZE
============================================================

For an ideal N-bit DAC with full-scale reference
Vref:

        Step size ≈ Vref / 2^N


Example:

        8-bit DAC
        Vref = 10 V


Step size:

        10 / 256
        = 0.0390625 V


Therefore:

        ≈ 39.06 mV


============================================================
18.21 DAC DIGITAL CODE EXAMPLE
============================================================

Suppose a 4-bit ideal DAC has:

        Vref = 16 V


There are:

        2^4 = 16 levels


The binary code:

        1010


has decimal value:

        10


Its ideal output is proportional to:

        10 / 16


So approximately:

        Vout = 16 × 10/16
             = 10 V


Depending on the DAC convention, the exact formula
may use a denominator of 2^N rather than 2^N−1.

Always follow the formula given in the problem.

18.25 FLASH ADC
============================================================

Flash ADC is one of the fastest ADC architectures.


Basic concept:

        Analog input
             |
       +-----+-----+
       |           |
      Comp       Comp
       |           |
      Comp       Comp
       |           |
       +-----+-----+
             |
          Encoder
             |
             v
       Digital output


Flash ADC uses multiple comparators operating
in parallel.


============================================================
18.26 FLASH ADC NUMBER OF COMPARATORS
============================================================

For an N-bit flash ADC:

        Number of comparators
        =
        2^N - 1


Example:

        3-bit Flash ADC:


        2^3 - 1
        = 7 comparators


4-bit Flash ADC:

        2^4 - 1
        = 15 comparators


8-bit Flash ADC:

        2^8 - 1
        = 255 comparators


This is a very important formula.


============================================================
18.27 FLASH ADC WORKING
============================================================

Suppose the input voltage is:

        Vin


A resistor ladder creates reference levels.


        Vref
         |
        R
         +---- Comparator
         |
        R
         +---- Comparator
         |
        R
         +---- Comparator
         |
        R
         |
        GND


All comparators compare Vin with different
reference voltages simultaneously.


Comparator outputs form a thermometer-like code.


Then:

        Comparator outputs
                ↓
             Encoder
                ↓
          Binary output

Advantages:

    + Very fast

    + Suitable for high-speed applications


Disadvantages:

    - High hardware cost

Memory:

============================================================
18.30 SAR ADC WORKING
============================================================

Suppose we have a 4-bit ADC.


The SAR tests bits from:

        MSB → LSB


First:

        1000


Comparator checks whether this value is too high
or too low.


Then the SAR decides whether to keep or clear
that bit.


Next bit is tested.


Conceptually:

        Start
          |
          v
        Test MSB
          |
          v
        Test next bit
          |
          v
        Test next bit
          |
          v
        Test LSB
          |
          v
        Final code


This is similar to binary search.


============================================================
18.31 SAR EXAMPLE
============================================================

Suppose the ADC is 4-bit.


Possible codes:

        0000
        ...
        1111


The SAR might test:

        1000


If Vin is greater than the DAC output:

        keep 1


If Vin is lower:

        clear 1


Then test:

        1100
        or
        1000


and continue.


Eventually:

        Final binary code


is obtained.

============================================================
18.33 COUNTER-TYPE ADC
============================================================

Also called:

        Digital ramp ADC


Basic structure:

        Clock
          |
       Counter
          |
          v
         DAC
          |
          v
       Comparator
          ^
          |
         Vin


Working:

    1. Counter starts from 0.
    2. Counter output goes to DAC.
    3. DAC produces an analog voltage.
    4. Comparator compares DAC output with Vin.
    5. Counter continues until DAC output reaches
       or crosses the input level.
    6. Counter value becomes digital output.


============================================================
18.34 COUNTER ADC EXAMPLE
============================================================

Suppose:

        Vin = 3 V


Counter produces:

        000
        001
        010
        011
        ...

DAC output rises step by step.


When DAC output becomes close to Vin:

        Stop counting.


The counter value represents Vin.


============================================================
18.35 COUNTER ADC ADVANTAGES
============================================================

Advantages:

    + Simple design
    + Easy to understand
    + Low hardware complexity


Disadvantages:

    - Slow
    - Conversion time depends on input value
    - Worst-case conversion can take many clock cycles


Memory:

        COUNTER ADC = SIMPLE BUT SLOW

18.36 DUAL-SLOPE ADC
============================================================

Dual-slope ADC is widely used where accuracy and
noise rejection are important.


Common applications:

        Digital multimeters


Basic idea:

        Integrator
           ^
           |
        Analog input
           |
           v
        Integration
           |
           v
        Reference
           |
           v
        De-integration
           |
           v
        Counter
           |
           v
        Digital output


============================================================
18.37 DUAL-SLOPE WORKING
============================================================

It has two major integration phases.


PHASE 1:

        Integrate the unknown input voltage.


PHASE 2:

        Apply a known reference voltage of
        opposite polarity and integrate back
        toward zero.


The time required to return to zero is measured.


That time is proportional to the input voltage.


Concept:

        Input integration
              /
             /
            /
           /
          /


        Return using reference
              \
               \
                \
                 \____ 0


The measured time determines the digital value.


============================================================
18.38 WHY DUAL-SLOPE IS USEFUL
============================================================

Advantages:

    + High accuracy
    + Good noise rejection
    + Excellent for measurement instruments


Disadvantages:

    - Slow conversion
    - Not suitable for high-speed applications


Memory:

        DUAL-SLOPE = ACCURATE BUT SLOW

============================================================
18.41 BINARY-WEIGHTED RESISTOR DAC
============================================================

It uses resistors having binary-weighted values.


For a 4-bit DAC:

        R
        2R
        4R
        8R


Conceptual structure:

        b3 ──R────\
                   \
        b2 ──2R────\
                     >---- Op-amp ---- Vout
        b1 ──4R────/
                   /
        b0 ──8R───/


MSB receives the largest contribution.


Because:

        MSB has highest weight.


============================================================
18.42 BINARY-WEIGHTED DAC WORKING
============================================================

For a binary number:

        b3 b2 b1 b0


The output is proportional to:

        b3/2
      + b2/4
      + b1/8
      + b0/16


with the overall scaling determined by the
reference voltage and circuit configuration.


Therefore each bit has a binary weight.


============================================================
18.43 BINARY-WEIGHTED DAC ADVANTAGES
============================================================

Advantages:

    + Simple concept
    + Fast operation
    + Direct binary weighting


Disadvantages:

    - Requires several precise resistor values
    - Resistor matching becomes difficult
      at high resolution
    - Large resistor range may be required


============================================================
18.44 R-2R LADDER DAC
============================================================

R-2R ladder DAC uses only two resistor values:

        R
        2R


This is its major advantage.


Concept:

        b3      b2      b1      b0
         |       |       |       |
         v       v       v       v
        [R-2R ladder network]
                  |
                  v
                Vout


The repeated structure makes accurate resistor
matching easier.


============================================================
18.45 R-2R LADDER ADVANTAGES
============================================================

Advantages:

    + Only R and 2R resistor values
    + Easier fabrication
    + Good scalability
    + Common practical DAC architecture


Disadvantages:

    - Switching and resistor matching still matter
    - Circuit design is somewhat more involved


Memory:

        R-2R = ONLY TWO RESISTOR VALUES

18.47 DAC RESOLUTION VS ADC RESOLUTION
============================================================

Both use the idea:

        N bits → 2^N codes/levels


For ADC:

        More bits
        → smaller input step
        → finer measurement


For DAC:

        More bits
        → smaller output step
        → finer analog approximation


============================================================
18.48 ACCURACY
============================================================

Resolution and accuracy are NOT the same.


RESOLUTION:

    How small a change can be distinguished.


ACCURACY:

    How close the actual result is to the
    desired/ideal value.


Example:

A measuring system may have:

        Very fine resolution

but still have:

        Calibration error


Therefore:

        High resolution ≠ automatically high accuracy


============================================================
18.49 CONVERSION TIME
============================================================

Conversion time is the time required by an ADC
to produce a digital result after receiving
an analog input.


Smaller conversion time:

        Faster ADC


Examples:

        Flash → very fast

        SAR → moderate/fast

        Counter → potentially slow

        Dual-slope → slow


============================================================
18.50 SAMPLING THEOREM
============================================================

The sampling theorem is fundamental to digital
signal processing.


For a band-limited analog signal with maximum
frequency:

        fmax


The sampling frequency must satisfy:

        fs > 2fmax


This is the Nyquist sampling condition.


============================================================
18.51 NYQUIST RATE
============================================================

The minimum theoretical sampling rate required
to perfectly reconstruct a band-limited signal is:

        Nyquist rate = 2fmax


Example:

        Maximum signal frequency = 5 kHz


Nyquist rate:

        2 × 5 kHz
        = 10 kHz


Therefore:

        fs > 10 kHz

is required for ideal sampling according to
the strict sampling theorem.


============================================================
18.52 NYQUIST FREQUENCY
============================================================

The Nyquist frequency is:

        fs / 2


where fs is the sampling frequency.


Example:

        fs = 20 kHz


Nyquist frequency:

        20/2
        = 10 kHz


IMPORTANT:

        Nyquist rate:
            2fmax


        Nyquist frequency:
            fs/2


Do not confuse them.


============================================================
18.53 SAMPLING EXAMPLE
============================================================

Suppose an audio signal contains frequencies
up to:

        20 kHz


Required sampling rate:

        fs > 2 × 20 kHz

        fs > 40 kHz


A common practical audio sampling rate is:

        44.1 kHz


which is greater than 40 kHz.


This allows frequencies up to 20 kHz to be
represented under ideal assumptions.


============================================================
18.54 WHAT IS ALIASING?
============================================================

Aliasing occurs when a signal is sampled too slowly,
causing different frequency components to become
indistinguishable after sampling.


Simple idea:

        HIGH-frequency signal
                |
        insufficient sampling
                |
                v
        appears as a LOWER-frequency signal


Therefore:

        Aliasing = frequency misrepresentation
        caused by insufficient sampling.


============================================================
18.55 ALIASING VISUALIZATION
============================================================

Original high-frequency waveform:

        /\/\/\/\/\/\/\/\/\/\/\


Samples:

        •   •   •   •   •   •


The sample points may appear to form a much
slower waveform:

        \        /
         \      /
          \____/


The reconstructed signal can therefore be wrong.


============================================================
18.56 HOW TO PREVENT ALIASING
============================================================

Main technique:

        Use sufficient sampling frequency.


Also use:

        ANTI-ALIASING FILTER


Before ADC:

        Analog signal
             |
             v
      Low-pass filter
             |
             v
            ADC
             |
             v
          Digital


The filter removes frequencies above the desired
band before sampling.


============================================================
18.57 ANTI-ALIASING FILTER
============================================================

An anti-aliasing filter is generally a
LOW-PASS FILTER placed before the ADC.


Purpose:

        Remove unwanted high-frequency components
        before sampling.


Structure:

        Analog signal
              |
              v
       +-------------+
       | Anti-alias  |

       +-------------+
              |
              v

        30 kHz


Practical sampling frequency should be greater
than 30 kHz.

18.65 SOLVED NUMERICAL 4
============================================================

Question:

A 12-bit ADC has a 3.3 V reference.
Find the approximate LSB size.


        2^12 = 4096


        Resolution
        = 3.3 / 4096

        ≈ 0.0008057 V


Therefore:

        ≈ 0.806 mV

        2fmax

        fs/2

        2^N - 1

        2^N

    into binary codes.
