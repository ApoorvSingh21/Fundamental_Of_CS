============================================================
1.1 WHAT IS A COMPUTER?
============================================================

1.1.1 Definition of a Computer

A computer is an electronic programmable machine that:

    Input → Processes Data → Produces Output

It can:
    - Accept data
    - Store data and instructions
    - Process data
    - Make logical decisions
    - Produce useful information
    - Communicate with other devices

Simple example:

    You type:
        25 + 35

    Computer:
        Receives 25 and 35
        Performs addition
        Produces 60

    Therefore:

        Input → Processing → Output
        25,35 → Addition   → 60


------------------------------------------------------------
1.1.2 Characteristics of Computers
------------------------------------------------------------

1. Speed
   - Computers perform millions/billions of operations per second.

2. Accuracy
   - Computers produce highly accurate results when
     instructions and input are correct.

3. Automation
   - Once a program is started, the computer can perform
     tasks automatically.

4. Storage
   - Computers can store large amounts of data.

5. Diligence
   - Computers do not get tired or bored from repetitive tasks.

6. Versatility
   - The same computer can perform many different tasks.

7. Reliability
   - Computers can repeatedly perform operations consistently.

8. Programmability
   - A computer can be programmed to perform different tasks.

9. Multitasking
   - Modern operating systems can allow multiple programs
     to run apparently at the same time.

10. Connectivity
    - Computers can communicate through networks and the Internet.


------------------------------------------------------------
1.1.3 Limitations of Computers
------------------------------------------------------------

Computers do NOT naturally possess:

    - Human intelligence
    - Common sense
    - Emotions
    - Independent understanding
    - Human judgment

A computer follows instructions and processes data according
to its hardware and software.

Important:

    Garbage In → Garbage Out (GIGO)

If the input or instructions are wrong,
the output can also be wrong.


------------------------------------------------------------
1.1.4 Why Are Computers Needed?
------------------------------------------------------------

Computers are used because they can:

    - Process huge amounts of data
    - Perform calculations quickly
    - Store large amounts of information
    - Automate repetitive tasks
    - Control machines
    - Communicate information
    - Solve complex computational problems
    - Support scientific research
    - Run business applications
    - Provide entertainment
    - Enable artificial intelligence and machine learning

Examples:

    Banking
    Education
    Healthcare
    Engineering
    Scientific research
    Manufacturing
    Transportation
    Communication
    Entertainment
    Defence


------------------------------------------------------------
1.1.5 Basic Working Principle
------------------------------------------------------------

The fundamental working model is:

            +----------------+
            |   INPUT UNIT   |
            +-------+--------+
                    |
                    v
            +----------------+
            |   PROCESSING   |
            |      UNIT      |
            +-------+--------+
                    |
                    v
            +----------------+
            |  OUTPUT UNIT   |
            +----------------+

Memory is involved throughout the process.

More complete model:

                 +----------------+
                 |   INPUT UNIT   |
                 +-------+--------+
                         |
                         v
              +----------------------+
              |         CPU          |
              |                      |
              |  +------+  +------+  |
              |  | ALU  |  |  CU  |  |
              |  +------+  +------+  |
              |       Registers      |
              +----------+-----------+
                         |
                         v
                 +---------------+
                 |    MEMORY     |
                 +---------------+
                         |
                         v
                 +---------------+
                 |  OUTPUT UNIT |
                 +---------------+


------------------------------------------------------------
1.1.6 Input → Processing → Output
------------------------------------------------------------

This is called the IPO model.

IPO = Input → Processing → Output

Example:

    Problem:
        Calculate salary.

    INPUT:
        Basic salary
        Allowances
        Deductions

    PROCESSING:
        CPU performs calculations.

    OUTPUT:
        Net salary


Another example:

    Keyboard
       ↓
    Input
       ↓
    CPU processes data
       ↓
    Monitor
       ↓
    Output


------------------------------------------------------------
1.1.7 Data vs Information
------------------------------------------------------------

DATA:

    Raw facts and figures that have not yet been processed.

Examples:
    80
    90
    70

INFORMATION:

    Meaningful result obtained after processing data.

Example:

    Data:
        80, 90, 70

    Processing:
        Calculate average

    Information:
        Average = 80


Key difference:

    DATA
      ↓
    Processing
      ↓
    INFORMATION


Remember:

    Data = Raw facts
    Information = Processed, meaningful data

1.2 EVOLUTION OF COMPUTERS
============================================================

Computers developed through several major stages.

Basic evolution:

    Mechanical
       ↓
    Vacuum Tubes
       ↓
    Transistors
       ↓
    Integrated Circuits
       ↓
    Microprocessors
       ↓
    Modern Computing


------------------------------------------------------------
1.2.1 Mechanical Computers
------------------------------------------------------------

Mechanical computers used mechanical components such as
gears, wheels and levers.

Important examples:

    - Abacus
    - Pascaline
    - Leibniz calculator
    - Charles Babbage's Difference Engine
    - Charles Babbage's Analytical Engine

Charles Babbage is commonly called:

    "Father of the Computer"


------------------------------------------------------------
1.2.2 Abacus
------------------------------------------------------------

The abacus is an ancient calculating device.

It uses movable beads to represent numbers.

Important:

    Abacus is NOT an electronic computer.

It is an early calculating tool.


------------------------------------------------------------
1.2.3 Pascaline
------------------------------------------------------------

Developed by:

    Blaise Pascal

It was a mechanical calculator designed mainly for
arithmetic operations.


------------------------------------------------------------
1.2.4 Charles Babbage
------------------------------------------------------------

Charles Babbage designed:

    Difference Engine
    Analytical Engine

The Analytical Engine contained ideas similar to
modern computer concepts:

    - Input
    - Processing
    - Memory
    - Output
    - Control

Therefore Babbage is known as:

    Father of the Computer


------------------------------------------------------------
1.2.5 First Generation Computers
------------------------------------------------------------

Approximate period:

    1940s – mid-1950s

Main technology:

    Vacuum tubes

Characteristics:

    - Very large
    - High power consumption
    - Generated a lot of heat
    - Expensive
    - Less reliable
    - Machine-language programming

Examples:

    - ENIAC
    - EDVAC
    - UNIVAC I

Memory:

    Magnetic drums were used in some systems.


------------------------------------------------------------
1.2.6 Second Generation Computers
------------------------------------------------------------

Approximate period:

    Mid-1950s – mid-1960s

Main technology:

    Transistors

Advantages over vacuum tubes:

    - Smaller
    - Faster
    - More reliable
    - Lower power consumption
    - Less heat

Programming:

    - Assembly language
    - Early high-level languages


------------------------------------------------------------
1.2.7 Third Generation Computers
------------------------------------------------------------

Approximate period:

    Mid-1960s – early 1970s

Main technology:

    Integrated Circuits (ICs)

An IC can contain multiple electronic components
on a small semiconductor chip.

Advantages:

    - Smaller
    - Faster
    - More reliable
    - Lower cost
    - Lower power consumption


------------------------------------------------------------
1.2.8 Fourth Generation Computers
------------------------------------------------------------

Approximate period:

    From the 1970s onward

Main technology:

    Microprocessors

A microprocessor integrates major CPU functions
onto a single chip.

Important developments:

    - Personal computers
    - Microcomputers
    - LSI/VLSI technology
    - Modern operating systems
    - Networking

Examples of processor families include:

    Intel
    AMD
    ARM


------------------------------------------------------------
1.2.9 Fifth Generation Computers
------------------------------------------------------------

The term "fifth generation" is often associated with:

    - Artificial Intelligence
    - Natural language processing
    - Knowledge-based systems
    - Parallel processing
    - Advanced robotics

Important:

    The generation classification is historical and
    is not a strict technical classification of every
    modern computer.


------------------------------------------------------------
1.2.10 Modern Computers
------------------------------------------------------------

Modern computers use technologies such as:

    - Multicore CPUs
    - GPUs
    - High-speed memory
    - SSDs
    - Cloud computing
    - AI accelerators
    - High-speed networks
    - Virtualization

Modern systems may contain:

    CPU + GPU + Memory + Storage + I/O controllers

============================================================
1.4 BASIC COMPUTER SYSTEM
============================================================

A basic computer consists of:

    1. Input Unit
    2. Output Unit
    3. Memory Unit
    4. ALU
    5. Control Unit
    6. CPU
    7. System Bus


------------------------------------------------------------
1.4.1 Input Unit
------------------------------------------------------------

The input unit accepts data and instructions
from the outside world.

Examples:

    - Keyboard
    - Mouse
    - Scanner
    - Microphone
    - Camera
    - Touchscreen

Basic function:

    User
      ↓
    Input device
      ↓
    Computer


------------------------------------------------------------
1.4.2 Output Unit
------------------------------------------------------------

The output unit presents processed information
to the user or another system.

Examples:

    - Monitor
    - Printer
    - Speaker
    - Projector


------------------------------------------------------------
1.4.3 Memory Unit
------------------------------------------------------------

Memory stores:

    - Data
    - Instructions
    - Intermediate results
    - Final results

Two broad categories:

    Primary memory
        - RAM
        - ROM

    Secondary storage
        - SSD
        - HDD


------------------------------------------------------------
1.4.4 Arithmetic Logic Unit (ALU)
------------------------------------------------------------

ALU = Arithmetic Logic Unit

It performs:

    Arithmetic operations:
        - Addition
        - Subtraction
        - Increment
        - Decrement

    Logical operations:
        - AND
        - OR
        - NOT
        - XOR
        - Comparisons

Example:

    10 + 20

    ALU performs:
        10 + 20 = 30


------------------------------------------------------------
1.4.5 Control Unit (CU)
------------------------------------------------------------

The Control Unit controls and coordinates
computer operations.

It:

    - Fetches instructions
    - Decodes instructions
    - Generates control signals
    - Coordinates ALU, registers, memory and I/O

Important:

    ALU = Performs operations

    CU = Controls operations


------------------------------------------------------------
1.4.6 CPU
------------------------------------------------------------

CPU = Central Processing Unit

It is the main processing component of a computer.

Basic CPU components:

    CPU
    ├── ALU
    ├── Control Unit
    └── Registers

Modern CPUs also contain many other components,
such as:

    - Cache
    - Multiple cores
    - Branch prediction hardware
    - Load/store units
    - Floating-point units


------------------------------------------------------------
1.4.7 Registers
------------------------------------------------------------

Registers are very small and very fast storage
locations inside the CPU.

They temporarily hold:

    - Data
    - Addresses
    - Instructions
    - Intermediate results
    - CPU state

Examples:

    PC
    IR
    MAR
    MDR
    General-purpose registers


------------------------------------------------------------
1.4.8 System Bus
------------------------------------------------------------

A bus is a communication pathway used to transfer
information between computer components.

Traditional classification:

    1. Address Bus
    2. Data Bus
    3. Control Bus


ADDRESS BUS:
    Carries addresses.

DATA BUS:
    Carries data.

CONTROL BUS:
    Carries control signals.


Simplified:

            CPU
          /  |  \
         /   |   \
    Address Data Control
      Bus    Bus   Bus
         \   |   /
          Memory/I/O


============================================================
1.5 COMPUTER ARCHITECTURE VS COMPUTER ORGANISATION
============================================================

This is one of the most important COA concepts.


------------------------------------------------------------
1.5.1 Computer Architecture
------------------------------------------------------------

Computer architecture describes the programmer-visible
and functional characteristics of a computer system.

It answers questions such as:

    - What instructions does the CPU support?
    - What registers are visible?
    - What data types are supported?
    - How are instructions represented?
    - What addressing modes exist?
    - What memory model is exposed?

Important concept:

    ISA (Instruction Set Architecture)

ISA acts as an interface between software and hardware.


------------------------------------------------------------
1.5.2 Computer Organisation
------------------------------------------------------------

Computer organisation describes how the architectural
features are implemented internally.

It deals with:

    - Control signals
    - Datapaths
    - ALU implementation
    - Cache organisation
    - Bus organisation
    - Memory technology
    - Pipeline implementation
    - Internal hardware connections


------------------------------------------------------------
1.5.3 Architecture vs Organisation
------------------------------------------------------------

ARCHITECTURE:

    What the computer does / presents to software

ORGANISATION:

    How the computer implements it internally


Example:

Two processors may implement the same ISA.

Therefore:

    Same architecture
          +
    Different internal organisation
          =
    Different processor implementations


------------------------------------------------------------
1.5.4 Hardware vs Software
------------------------------------------------------------

HARDWARE:

Physical components.

Examples:

    CPU
    RAM
    SSD
    Keyboard
    Monitor
    Motherboard

SOFTWARE:

Programs and instructions.

Examples:

    Operating system
    Compiler
    Browser
    Games
    Applications


Relationship:

    Software
       ↓
    Instructions
       ↓
    ISA
       ↓
    Hardware


------------------------------------------------------------
1.5.5 ISA as Hardware-Software Interface
------------------------------------------------------------

ISA = Instruction Set Architecture

It defines the interface between:

    Software
         ↕
       ISA
         ↕
    Hardware

Software generates/uses machine instructions
defined by the ISA.

Hardware executes those instructions.


Examples of ISAs:

    - x86-64
    - ARM
    - RISC-V
    - MIPS


============================================================
1.6 VON NEUMANN ARCHITECTURE
============================================================

Von Neumann architecture is based on the
stored-program concept.


------------------------------------------------------------
1.6.1 Stored-Program Concept
------------------------------------------------------------

Instructions and data are stored in memory.

This was a fundamental idea in modern computer design.

Instead of building a machine for only one fixed task,
a computer can store a program in memory and execute it.


Basic concept:

    Memory
    ┌──────────────────────┐
    │ Instructions         │
    │ Data                 │
    │ Instructions         │
    │ Data                 │
    └──────────┬───────────┘
               │
               v
              CPU


------------------------------------------------------------
1.6.2 Main Components
------------------------------------------------------------

A basic Von Neumann system contains:

    1. CPU
       - ALU
       - Control Unit
       - Registers

    2. Memory

    3. Input

    4. Output


------------------------------------------------------------
1.6.3 Von Neumann Model
------------------------------------------------------------

                 +------------------+
                 |      INPUT       |
                 +--------+---------+
                          |
                          v
                 +------------------+
                 |      MEMORY      |
                 |                  |
                 | Instructions     |
                 | Data             |
                 +--------+---------+
                          |
                          |
                          v
              +-----------------------+
              |         CPU           |
              |                       |
              |  +------+   +------+ |
              |  | ALU  |   |  CU  | |
              |  +------+   +------+ |
              |     Registers         |
              +-----------+-----------+
                          |
                          v
                 +------------------+
                 |      OUTPUT      |
                 +------------------+


------------------------------------------------------------
1.6.4 Basic Instruction Execution
------------------------------------------------------------

The CPU generally performs:

    FETCH
      ↓
    DECODE
      ↓
    EXECUTE
      ↓
    STORE/WRITE BACK

FETCH:
    Get instruction from memory.

DECODE:
    Determine what the instruction means.

EXECUTE:
    Perform the required operation.

WRITE BACK:
    Store the result where required.


------------------------------------------------------------
1.6.5 Von Neumann Bottleneck
------------------------------------------------------------

In the traditional Von Neumann model,
instructions and data share the same memory path.

Therefore, CPU access to instructions and data
can compete for the same communication resources.

This limits the rate at which information can move
between CPU and memory.

This is called:

    Von Neumann Bottleneck


Simple idea:

    Very fast CPU
          ↓
    Slow/limited memory path
          ↓
    CPU may have to wait


Modern computers reduce this problem using techniques such as:

    - Cache memory
    - Multiple cache levels
    - Wider memory interfaces
    - Prefetching
    - Multiple execution units
    - More advanced memory systems


------------------------------------------------------------
1.6.6 Advantages of Von Neumann Architecture
------------------------------------------------------------

    - Simple conceptual design
    - Flexible
    - Instructions stored in memory
    - Programs can be changed easily
    - Same memory can store data and instructions
    - Suitable for general-purpose computing


------------------------------------------------------------
1.6.7 Limitations of Von Neumann Architecture
------------------------------------------------------------

    - Shared instruction/data path can create bottlenecks
    - CPU may wait for memory
    - Instruction and data accesses compete
    - Memory bandwidth can limit performance


============================================================
1.7 HARVARD ARCHITECTURE
============================================================

Harvard architecture uses separate memory systems
for instructions and data.

Therefore:

    Instruction memory ≠ Data memory


------------------------------------------------------------
1.7.1 Separate Instruction and Data Memory
------------------------------------------------------------

Concept:

        Instruction Memory
              |
              |
              v
             CPU
              ^
              |
              |
           Data Memory


The CPU can potentially access:

    Instruction memory
    and
    Data memory

independently.


------------------------------------------------------------
1.7.2 Harvard Architecture Diagram
------------------------------------------------------------

          +-----------------------+
          |   INSTRUCTION MEMORY  |
          +-----------+-----------+
                      |
               Instruction Bus
                      |
                      v
                +----------+
                |   CPU    |
                +----------+
                      ^
                      |
                  Data Bus
                      |
          +-----------+-----------+
          |      DATA MEMORY      |
          +-----------------------+


------------------------------------------------------------
1.7.3 Advantages of Harvard Architecture
------------------------------------------------------------

    - Separate instruction and data paths
    - Instruction and data accesses can occur simultaneously
    - Higher potential memory bandwidth
    - Reduced instruction/data access conflict
    - Useful in predictable/high-throughput systems


------------------------------------------------------------
1.7.4 Limitations of Harvard Architecture
------------------------------------------------------------

    - More complex hardware
    - Separate memories can be less flexible
    - More complicated memory organisation
    - Data and instruction storage may have different constraints


------------------------------------------------------------
1.7.5 Modified Harvard Architecture
------------------------------------------------------------

Modern processors often use a modified Harvard design.

Typical example:

    CPU
     |
     +---- Instruction Cache
     |
     +---- Data Cache
              |
              v
          Shared Main Memory


Concept:

    L1 Instruction Cache
            +
    L1 Data Cache
            ↓
    Shared lower-level memory/cache


This combines advantages of both approaches.


------------------------------------------------------------
1.7.6 Practical Applications
------------------------------------------------------------

Harvard-style designs are common in:

    - Microcontrollers
    - Digital Signal Processors (DSPs)
    - Embedded systems
    - Some modern CPU cache hierarchies


============================================================
VON NEUMANN vs HARVARD
============================================================

+----------------------+----------------------+----------------------+
| Feature              | Von Neumann          | Harvard              |
+----------------------+----------------------+----------------------+
| Instruction memory  | Shared               | Separate             |
| Data memory         | Shared               | Separate             |
| Instruction bus     | Shared path          | Separate path        |
| Data bus             | Shared path          | Separate path        |
| Simultaneous access | More limited         | Easier               |
| Complexity           | Simpler              | More complex         |
| Flexibility          | Higher               | Lower in classic form|
| Main idea            | One memory           | Two memories         |
+----------------------+----------------------+----------------------+

    +--------------+
