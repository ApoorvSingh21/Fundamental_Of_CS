2.1 WHAT IS DATA COMMUNICATION?
======================================================================

Data communication is the exchange of data between two or more
devices through a communication medium using agreed communication
rules (protocols).

Simple model:

    Sender
       |
       | Data
       ↓
    Communication Medium
       |
       ↓
    Receiver


Example:

    Laptop A
       |
       | Wi-Fi
       ↓
    Router
       |
       ↓
    Laptop B


Here:

    Laptop A       = Sender
    Laptop B       = Receiver
    Wi-Fi/network  = Communication medium
    Data           = Message
    Protocol       = Rules


======================================================================
2.2 BASIC COMPONENTS OF DATA COMMUNICATION
======================================================================

A basic communication system has five major components:

    1. Sender
    2. Receiver
    3. Message
    4. Transmission medium
    5. Protocol


                    MESSAGE
                       |
                       ↓
    SENDER ───→ TRANSMISSION MEDIUM ───→ RECEIVER
                       ↑
                       |
                    PROTOCOL


----------------------------------------------------------------------
2.2.1 SENDER
----------------------------------------------------------------------

Sender is the device that generates and sends data.

Examples:

    - Computer
    - Smartphone
    - Server
    - Sensor
    - Camera


Example:

    PC A ─────────→ PC B

    PC A = Sender


----------------------------------------------------------------------
2.2.2 RECEIVER
----------------------------------------------------------------------

Receiver is the device that receives the transmitted data.

Example:

    PC A ─────────→ PC B

    PC B = Receiver


----------------------------------------------------------------------
2.2.3 MESSAGE
----------------------------------------------------------------------

Message is the information being transmitted.

It can be:

    - Text
    - Number
    - Image
    - Audio
    - Video
    - File
    - Application data


Example:

    "Hello"

    This is the message.


----------------------------------------------------------------------
2.2.4 TRANSMISSION MEDIUM
----------------------------------------------------------------------

Transmission medium is the path through which data travels.

Two broad categories:

    1. Guided / Wired
    2. Unguided / Wireless


Guided:

    - Twisted pair
    - Coaxial cable
    - Fiber optic


Unguided:

    - Radio
    - Microwave
    - Infrared
    - Satellite


----------------------------------------------------------------------
2.2.5 PROTOCOL
----------------------------------------------------------------------

Protocol is a set of rules used for communication.

Examples:

    TCP
    UDP
    IP
    HTTP
    DNS
    DHCP
    Ethernet


Without common protocols:

    Device A → ??? → Device B


With protocols:

    Device A → Agreed Rules → Device B


Therefore:

    Protocol = Rules governing communication.


======================================================================
2.3 CHARACTERISTICS OF EFFECTIVE DATA COMMUNICATION
======================================================================

A good communication system should provide:

    1. Delivery
    2. Accuracy
    3. Timeliness
    4. Low/controlled jitter where required


----------------------------------------------------------------------
2.3.1 DELIVERY
----------------------------------------------------------------------

Data must reach the correct destination.

Example:

    User A sends file to User B.

Correct:

    User A ───→ User B


Incorrect:

    User A ───→ User C


----------------------------------------------------------------------
2.3.2 ACCURACY
----------------------------------------------------------------------

Data should arrive without undetected corruption.

Sent:

    10110010


Received:

    10110010

Correct.


If received:

    10100010

A bit changed.

Error detection/correction mechanisms may be required.


----------------------------------------------------------------------
2.3.3 TIMELINESS
----------------------------------------------------------------------

Data should arrive within the required time.

Important for:

    - Video calls
    - Online gaming
    - Voice calls
    - Financial systems
    - Industrial control


A file transfer may tolerate some delay.

A voice call is much more sensitive to delay.


----------------------------------------------------------------------
2.3.4 JITTER
----------------------------------------------------------------------

Jitter is variation in packet delay.

Example:

    Packet 1 → 20 ms
    Packet 2 → 21 ms
    Packet 3 → 50 ms
    Packet 4 → 22 ms

The varying delay produces jitter.


High jitter is especially problematic for:

    - VoIP
    - Video conferencing
    - Real-time streaming
    - Gaming


======================================================================
2.4 DATA REPRESENTATION
======================================================================

Computers fundamentally process information using binary values:

    0
    1


Different types of information are encoded into bits.


----------------------------------------------------------------------
2.4.1 TEXT
----------------------------------------------------------------------

Characters can be represented using character encoding schemes.

Examples:

    ASCII
    Unicode
    UTF-8


Example:

    A → binary representation


Unicode supports a very large range of characters and symbols.


----------------------------------------------------------------------
2.4.2 NUMBERS
----------------------------------------------------------------------

Numbers are represented in binary.

Example:

    Decimal 5

    Binary:

    101


Because:

    1×2² + 0×2¹ + 1×2⁰
    = 4 + 0 + 1
    = 5


----------------------------------------------------------------------
2.4.3 IMAGE
----------------------------------------------------------------------

A digital image consists of pixels.

Each pixel can contain color information.

Example conceptual representation:

    Pixel → RGB values


Higher resolution generally means more pixels and therefore more
data.


----------------------------------------------------------------------
2.4.4 AUDIO
----------------------------------------------------------------------

Digital audio is commonly represented by sampling an analog
audio signal.

Important concepts:

    - Sampling rate
    - Quantization
    - Bit depth


Example:

    44.1 kHz audio

means:

    44,100 samples per second.


----------------------------------------------------------------------
2.4.5 VIDEO
----------------------------------------------------------------------

Video consists of a sequence of images/frames plus associated
audio and metadata.

Important concepts:

    - Resolution
    - Frame rate
    - Bit rate
    - Compression


Example:

    1920 × 1080
    60 frames/sec

2.5 DATA AND SIGNAL
======================================================================

Important distinction:

    DATA:
        Information to be communicated.

    SIGNAL:
        Physical/electromagnetic representation used to carry data.


Conceptually:

    Data
      ↓
    Encoding/Modulation
      ↓
    Signal
      ↓
    Transmission Medium
      ↓
    Signal
      ↓
    Decoding
      ↓
    Data


Example:

    Computer data
         ↓
    Electrical signal
         ↓
    Ethernet cable
         ↓
    Electrical signal
         ↓
    Receiving computer


======================================================================
2.6 ANALOG SIGNAL
======================================================================

An analog signal varies continuously over time.


Conceptually:

        /¯\       /¯\
       /   \     /   \
------/-----\---/-----\------
     /       \ /       \
    /         V         \


Examples:

    - Traditional voice signal
    - Radio signals
    - Some sensor outputs


Analog signals can have continuously varying values.


======================================================================
2.7 DIGITAL SIGNAL
======================================================================

A digital signal represents information using discrete levels.

Conceptually:

        ┌───────┐       ┌───────┐
        │       │       │       │
────────┘       └───────┘       └──────


Typical representation:

    High → 1
    Low  → 0


Digital communication is fundamental to modern computer networks.


======================================================================
2.8 ANALOG vs DIGITAL SIGNAL
======================================================================

    Feature             Analog              Digital
    -------------------------------------------------------
    Values              Continuous          Discrete
    Representation      Waveform            Discrete levels
    Noise sensitivity   Often higher        Can be more robust
    Processing          Analog circuitry     Digital processing
    Common use          Radio/audio         Computer networks


Important:

    Real communication systems can involve both analog and
    digital processing.


======================================================================
2.9 PERIODIC AND NON-PERIODIC SIGNALS
======================================================================

----------------------------------------------------------------------
PERIODIC SIGNAL
----------------------------------------------------------------------

A signal that repeats its pattern at regular intervals.

Example:

    /\/\ /\/\ /\/\ /\/\


If the pattern repeats every T seconds:

    T = Period


----------------------------------------------------------------------
NON-PERIODIC SIGNAL
----------------------------------------------------------------------

A signal that does not repeat regularly.

Example:

    /\___/\/____/\_/____


Digital data streams commonly produce non-periodic signal patterns.


======================================================================
2.10 IMPORTANT SIGNAL PARAMETERS
======================================================================

Four major concepts:

    1. Amplitude
    2. Period
    3. Frequency
    4. Phase


======================================================================
2.11 AMPLITUDE
======================================================================

Amplitude is the magnitude/strength of a signal relative to a
reference level.

Conceptually:

                Peak
                 ↑
                 |
              /¯¯¯\
             /     \
------------/-------\------------ Reference
           /         \
          /           \
                 |
                 ↓
             Amplitude


In communication systems, signal power/strength matters because
signals weaken as they travel.


======================================================================
2.12 PERIOD
======================================================================

Period is the time required for one complete cycle of a periodic
signal.

Symbol:

    T


Unit:

    seconds


Example:

    If one cycle takes 0.01 seconds:

    T = 0.01 s


======================================================================
2.13 FREQUENCY
======================================================================

Frequency is the number of cycles per second.

Symbol:

    f


Unit:

    Hertz (Hz)


Relationship:

    f = 1/T

and:

    T = 1/f


Example:

    T = 0.001 seconds

    f = 1 / 0.001
      = 1000 Hz


Therefore:

    f = 1 kHz


======================================================================
2.14 WAVELENGTH
======================================================================

Wavelength is the physical distance occupied by one complete cycle
of a wave.

Symbol:

    λ (lambda)


For a wave traveling at velocity v:

    λ = v / f


For electromagnetic waves in free space:

    approximately:

    v ≈ 3 × 10^8 m/s


Example:

    f = 100 MHz

    λ = (3 × 10^8) / (100 × 10^6)

      = 3 meters


======================================================================
2.15 PHASE
======================================================================

Phase describes the position of a waveform relative to a reference.

It is commonly measured in:

    degrees
    radians


One complete cycle:

    360° = 2π radians


Two waves can have the same:

    amplitude
    frequency

but different phase.


Concept:

    Wave A:  /\/\
    Wave B:    /\/\

The shift represents a phase difference.


======================================================================
2.16 BIT RATE
======================================================================

Bit rate is the number of bits transmitted per second.

Symbol:

    R


Units:

    bps
    Kbps
    Mbps
    Gbps
    Tbps


Examples:

    1,000 bps
    1 Mbps
    100 Mbps
    1 Gbps


Important:

    bit = b

    Byte = B


Therefore:

    1 Byte = 8 bits


Be careful:

    Mbps = megabits per second

    MB/s = megabytes per second


======================================================================
2.17 BAUD RATE
======================================================================

Baud rate represents the number of signal symbols transmitted per
second.

Important distinction:

    Bit rate ≠ always Baud rate.


If each symbol represents exactly one bit:

    Bit rate = Baud rate


If each symbol represents multiple bits:

    Bit rate > Baud rate


Formula:

    Bit Rate = Baud Rate × Bits per Symbol


Example:

    Baud rate = 1000 symbols/sec

    Each symbol carries 2 bits.

    Bit rate = 1000 × 2
             = 2000 bps


If each symbol carries 4 bits:

    Bit rate = 1000 × 4
             = 4000 bps


======================================================================
2.18 BIT vs SYMBOL
======================================================================

BIT:

    Basic binary information unit.

SYMBOL:

    A distinct signal state/waveform representing one or more bits.


Example:

    If 4 different signal symbols are used:

        Number of bits/symbol = log2(4)
                              = 2 bits


If:

    M = number of symbols

Then:

    Bits per symbol = log2(M)


Therefore:

    Bit Rate = Baud Rate × log2(M)


This is important for modulation and digital communication.


======================================================================
2.19 BANDWIDTH
======================================================================

The word "bandwidth" has context-dependent meanings.

In communication theory:

    Bandwidth = range of frequencies occupied by a signal/channel.

If:

    Highest frequency = fH
    Lowest frequency  = fL

Then:

    Bandwidth = fH - fL


Example:

    fL = 1 MHz
    fH = 5 MHz

    Bandwidth = 5 - 1
              = 4 MHz


In networking practice, "bandwidth" is also commonly used to mean
the nominal data-carrying capacity of a link, such as 100 Mbps or
1 Gbps.


Important:

    Frequency bandwidth and data-rate capacity are related,
    but they are not the same concept.


======================================================================
2.20 THROUGHPUT
======================================================================

Throughput is the actual rate at which data is successfully
delivered over a network.

Example:

    Link capacity = 100 Mbps

    Actual throughput = 80 Mbps


Therefore:

    Bandwidth/capacity = 100 Mbps
    Throughput          = 80 Mbps


Throughput can be affected by:

    - Congestion
    - Protocol overhead
    - Packet loss
    - Errors
    - Latency
    - Receiver limitations
    - Server limitations


======================================================================
2.21 GOODPUT
======================================================================

Goodput is the useful application-level data delivered per unit time,
excluding protocol/retransmission overhead depending on the exact
definition being used.

Conceptually:

    Throughput
       ↓
    Remove protocol overhead
    Remove retransmitted/unwanted data
       ↓
    Useful application data
       ↓
    GOODPUT


Typically:

    Goodput ≤ Throughput


======================================================================
2.22 LATENCY
======================================================================

Latency is the time associated with data traveling through a network
or completing a communication operation.


Example:

    Computer A → Server

    Response takes 30 ms.

    Approximately:

    RTT = 30 ms


Lower latency is generally desirable for interactive applications.


======================================================================
2.23 TYPES OF NETWORK DELAY
======================================================================

A packet's nodal delay can be divided into:

    1. Processing delay
    2. Queuing delay
    3. Transmission delay
    4. Propagation delay


Total nodal delay:

    d_total
      =
    d_processing
      +
    d_queuing
      +
    d_transmission
      +
    d_propagation


This is a very important exam/interview concept.


======================================================================
2.24 PROCESSING DELAY
======================================================================

Processing delay is the time required by a network device to:

    - Examine packet headers
    - Check for errors
    - Determine where to forward the packet
    - Perform necessary processing


Example:

    Router receives packet
          ↓
    Examine IP header
          ↓
    Find route
          ↓
    Forward packet


The time consumed is processing delay.


======================================================================
2.25 QUEUING DELAY
======================================================================

When packets arrive faster than they can be transmitted, they wait
in a queue.

Example:

                  Router
                    |
        +-----------+-----------+
        | Packet 1  | Packet 2  |
        | Packet 3  | Packet 4  |
        +-----------------------+
                    |
                  Link


Packets waiting in the buffer experience queuing delay.


Queuing delay depends heavily on:

    - Traffic load
    - Buffer size
    - Transmission rate
    - Traffic patterns


Under heavy congestion:

    Queuing delay ↑


======================================================================
2.26 TRANSMISSION DELAY
======================================================================

Transmission delay is the time required to push all bits of a packet
onto the communication link.

Formula:

    Transmission Delay
        =
    Packet Size / Transmission Rate


Where:

    Packet Size = bits
    Transmission Rate = bits/second


Example:

    Packet = 1,000 bits
    Link rate = 1,000,000 bits/sec

    Transmission delay
        = 1000 / 1,000,000
        = 0.001 sec
        = 1 ms


IMPORTANT:

    Transmission delay depends on:

        Packet size
        Link transmission rate


It does NOT directly depend on physical distance.


======================================================================
2.27 PROPAGATION DELAY
======================================================================

Propagation delay is the time required for a signal to physically
travel across the transmission medium.

Formula:

    Propagation Delay
        =
    Distance / Propagation Speed


Example:

    Distance = 1000 km
             = 1,000,000 m

    Propagation speed = 2 × 10^8 m/s


    Delay = 1,000,000 / (2 × 10^8)

          = 0.005 sec

          = 5 ms


Propagation delay depends mainly on:

    - Distance
    - Propagation speed of medium


It does NOT depend directly on packet size.


======================================================================
2.28 TRANSMISSION vs PROPAGATION DELAY
======================================================================

    Transmission Delay:

        Time to put packet bits onto link.

        Formula:
            L / R


    Propagation Delay:

        Time for signal to travel across link.

        Formula:
            d / s


Where:

    L = packet length in bits
    R = transmission rate in bits/sec
    d = distance
    s = propagation speed


Key difference:

    Transmission delay → packet size + link rate

    Propagation delay → distance + signal speed


This is a VERY IMPORTANT interview question.


======================================================================
2.29 EXAMPLE: TRANSMISSION vs PROPAGATION
======================================================================

Given:

    Packet size = 10,000 bits
    Link rate   = 10 Mbps
    Distance    = 1,000 km
    Propagation speed = 2 × 10^8 m/s


Step 1: Transmission delay

    10 Mbps = 10,000,000 bits/sec

    d_transmission
        = 10,000 / 10,000,000
        = 0.001 sec
        = 1 ms


Step 2: Propagation delay

    1,000 km = 1,000,000 m

    d_propagation
        = 1,000,000 / (2 × 10^8)
        = 0.005 sec
        = 5 ms


Total, ignoring processing and queuing:

    1 ms + 5 ms
    = 6 ms


======================================================================
2.30 BANDWIDTH-DELAY PRODUCT
======================================================================

Bandwidth-delay product (BDP) represents approximately how many bits
can be "in flight" on a link.

Formula:

    BDP = Bandwidth × Propagation Delay


Example:

    Bandwidth = 100 Mbps
    Propagation delay = 20 ms


    BDP
      = 100 × 10^6 × 0.020
      = 2,000,000 bits


Therefore:

    BDP = 2 Mbits


In bytes:

    2,000,000 / 8
    = 250,000 bytes


BDP is important for:

    - TCP performance
    - Window sizing
    - High-speed long-distance networks


======================================================================
2.31 DATA FLOW
======================================================================

Data communication can occur in three directions/modes:

    1. Simplex
    2. Half-duplex
    3. Full-duplex


======================================================================
2.32 SIMPLEX
======================================================================

Communication occurs in only one direction.

Example:

    Sender ─────────→ Receiver


Receiver cannot send data back through the same communication
relationship.


Examples:

    - Traditional broadcast-style communication
    - Some sensor/display arrangements


Concept:

    A → B

    NOT:

    B → A


======================================================================
2.33 HALF-DUPLEX
======================================================================

Both sides can communicate, but not simultaneously.

Example:

    A ─────────→ B

    then:

    A ←───────── B


Classic example:

    Walkie-talkie


One person speaks while the other listens.


======================================================================
2.34 FULL-DUPLEX
======================================================================

Both sides can transmit simultaneously.

Example:

    A ─────────→ B
    A ←───────── B


Examples:

    - Telephone conversation
    - Modern switched Ethernet communication


Full-duplex allows simultaneous two-way communication.


======================================================================
2.35 SIMPLEX vs HALF-DUPLEX vs FULL-DUPLEX
======================================================================

    Mode          Communication
    ---------------------------------------
    Simplex       One direction only
    Half-duplex  Both directions, one at a time
    Full-duplex  Both directions simultaneously


Memory:

    SIMPLEX:
        One-way


    HALF:
        Two-way, but turn-by-turn


    FULL:
        Two-way simultaneously


======================================================================
2.36 TRANSMISSION MODES
======================================================================

Data can also be transmitted using:

    - Serial transmission
    - Parallel transmission


======================================================================
2.37 SERIAL TRANSMISSION
======================================================================

Bits are transmitted sequentially over a communication path.

Example:

    Bits:

    1 → 0 → 1 → 1 → 0 → 0


Concept:

    Sender ================= Receiver

             1 0 1 1 0 0
             → → → → → →


Advantages:

    - Fewer wires
    - Suitable for long distances
    - Lower cabling complexity


Modern networking links predominantly use serial transmission.


Examples:

    - Ethernet
    - USB
    - Serial communication interfaces


======================================================================
2.38 PARALLEL TRANSMISSION
======================================================================

Multiple bits are transmitted simultaneously over multiple lines.

Example:

    Bit 1 ─────────────→
    Bit 2 ─────────────→
    Bit 3 ─────────────→
    Bit 4 ─────────────→


Four bits can be sent simultaneously.


Advantages:

    - Multiple bits transferred at once


Disadvantages:

    - More wires
    - Timing/skew issues over longer distances
    - Higher physical complexity


Parallel transmission is more common inside systems or over short
distances than in modern long-distance networking.


======================================================================
2.39 SERIAL vs PARALLEL
======================================================================

    Feature          Serial             Parallel
    ---------------------------------------------------
    Bits             Sequential         Multiple at once
    Wires             Fewer              More
    Long distance     Suitable           More difficult
    Complexity        Lower              Higher
    Modern networks   Very common        Less common


======================================================================
2.40 ASYNCHRONOUS TRANSMISSION
======================================================================

In asynchronous transmission, data is sent without requiring a
continuous shared clock between sender and receiver.

Individual characters/frames can be separated by start/stop bits
depending on the protocol.


Concept:

    START | DATA | STOP
    START | DATA | STOP


Example:

    UART-style serial communication.


Advantages:

    - Simple
    - Suitable for irregular data


Disadvantages:

    - Start/stop overhead
    - Lower efficiency for continuous high-volume data


======================================================================
2.41 SYNCHRONOUS TRANSMISSION
======================================================================

In synchronous transmission, data is transmitted in coordinated
blocks/frames using timing mechanisms.

Concept:

    [Header][Data][Data][Data][Trailer]


Advantages:

    - Efficient for continuous/high-volume data
    - Less per-character overhead


Used widely in high-speed networking systems.


======================================================================
2.42 SYNCHRONOUS vs ASYNCHRONOUS
======================================================================

    Feature          Synchronous       Asynchronous
    ----------------------------------------------------
    Timing           Coordinated       Not continuously shared
    Data             Blocks/frames     Characters/units
    Overhead         Generally lower   Start/stop overhead
    Efficiency       Higher            Lower for large streams
    Use               High-speed       Simple/irregular data


======================================================================
2.43 TRANSMISSION MEDIA
======================================================================

Transmission media are divided into:

    A. Guided media
    B. Unguided media


GUIDED:

    Signal travels through a physical medium.


UNGUIDED:

    Signal propagates through free space.


======================================================================
2.44 GUIDED MEDIA
======================================================================

Main types:

    1. Twisted pair
    2. Coaxial cable
    3. Fiber optic cable


======================================================================
2.45 TWISTED PAIR CABLE
======================================================================

Twisted pair consists of pairs of insulated copper wires twisted
together.

Example:

    Wire A ~~~~~
    Wire B ~~~~~

The twisting helps reduce electromagnetic interference and
crosstalk.


Types:

    UTP
    STP


======================================================================
2.46 UTP
======================================================================

UTP = Unshielded Twisted Pair

No additional metallic shielding around the twisted pairs.


Advantages:

    - Cheap
    - Easy to install
    - Flexible
    - Widely used in Ethernet LANs


Disadvantages:

    - More susceptible to interference than shielded alternatives
    - Distance limitations


Common Ethernet categories include:

    Cat5e
    Cat6
    Cat6a
    Cat8


Exact supported speed depends on category, distance, installation
and networking equipment.


======================================================================
2.47 STP
======================================================================

STP = Shielded Twisted Pair

Uses shielding to reduce electromagnetic interference.


Advantages:

    - Better protection against interference


Disadvantages:

    - More expensive
    - More difficult installation
    - Grounding requirements can matter


======================================================================
2.48 COAXIAL CABLE
======================================================================

Coaxial cable contains:

    - Central conductor
    - Insulator
    - Shield
    - Outer jacket


Concept:

        Outer Jacket
      ________________
     /                \
    |   Shield         |
    |  -------------   |
    | | Insulator   |  |
    | |     ●       |  |
    |  -------------   |
     \________________/


Uses historically/common in:

    - Cable television
    - Broadband systems
    - RF applications


Advantages:

    - Good shielding
    - Better interference resistance than simple unshielded wires


======================================================================
2.49 FIBER OPTIC CABLE
======================================================================

Fiber optic cable transmits information using light.

Basic structure:

    Core
    Cladding
    Protective coating/jacket


Concept:

        Jacket
      ___________
     /           \
    |  Cladding   |
    |   _______   |
    |  | CORE |   |
    |  |LIGHT |   |
    |  |______|   |
     \___________/


Types:

    1. Single-mode fiber
    2. Multimode fiber


======================================================================
2.50 SINGLE-MODE FIBER
======================================================================

Single-mode fiber supports propagation primarily along one mode/path
through a very small core.


Characteristics:

    - Long distance
    - Very high bandwidth
    - Low attenuation
    - Common in telecom/backbone links


Used for:

    - Long-distance networks
    - ISP backbones
    - Data-center interconnects


======================================================================
2.51 MULTIMODE FIBER
======================================================================

Multimode fiber allows multiple propagation modes.

Characteristics:

    - Shorter distances than single-mode
    - Larger core
    - Common in some enterprise/data-center environments


Comparison:

    Single-mode:
        Long distance


    Multimode:
        Shorter distance


======================================================================
2.52 FIBER ADVANTAGES
======================================================================

Advantages:

    - Very high bandwidth
    - Long transmission distances
    - Low attenuation
    - Immune to electromagnetic interference
    - Difficult to tap physically compared with copper


Disadvantages:

    - Higher installation complexity
    - More delicate
    - Specialized tools/skills
    - Transceivers/connectors can cost more


======================================================================
2.53 GUIDED MEDIA COMPARISON
======================================================================

    Medium        Main Property
    ---------------------------------------------
    UTP           Cheap, common LAN cabling
    STP           Better EMI protection
    Coaxial       Strong shielding, RF/broadband
    Fiber         High bandwidth, long distance


======================================================================
2.54 UNGUIDED MEDIA
======================================================================

Unguided media transmit electromagnetic waves through air/free space.


Examples:

    - Radio waves
    - Microwaves
    - Infrared
    - Satellite communication


======================================================================
2.55 RADIO WAVES
======================================================================

Radio waves are used for wireless communication.

Examples:

    - Wi-Fi
    - Bluetooth
    - Cellular communication
    - Broadcast radio


Advantages:

    - Mobility
    - No physical cable for the wireless portion


Challenges:

    - Interference
    - Security
    - Signal attenuation
    - Spectrum limitations


======================================================================
2.56 MICROWAVE
======================================================================

Microwave communication commonly uses directional high-frequency
radio signals.

Applications:

    - Point-to-point wireless links
    - Backhaul
    - Satellite communication


Some terrestrial microwave links require line-of-sight conditions.


======================================================================
2.57 INFRARED
======================================================================

Infrared uses electromagnetic radiation in the infrared range.

Characteristics:

    - Short range
    - Often line-of-sight
    - Does not generally penetrate walls effectively


Historically used in:

    - Remote controls
    - Short-range device communication


======================================================================
2.58 SATELLITE COMMUNICATION
======================================================================

Communication can use satellites as relay stations.

Concept:

    Ground Station
          |
          ↑
          |
       Satellite
          |
          ↓
          |
    Ground Station


Advantages:

    - Very large geographical coverage
    - Useful for remote regions


Disadvantages:

    - Higher latency for many satellite systems
    - Expensive infrastructure
    - Weather/environmental considerations depending on frequency


Modern low-Earth-orbit systems can have substantially lower latency
than traditional high-altitude geostationary systems.


======================================================================
2.59 SWITCHING TECHNIQUES
======================================================================

Switching determines how data is moved through intermediate network
nodes.


Major historical/general concepts:

    1. Circuit switching
    2. Message switching
    3. Packet switching


======================================================================
2.60 CIRCUIT SWITCHING
======================================================================

A dedicated communication path is established for the duration of
the communication session.


Concept:

    A ───────── Dedicated Path ───────── B


Phases:

    1. Circuit establishment
    2. Data transfer
    3. Circuit termination


Advantages:

    - Predictable dedicated path
    - Consistent resource allocation once established


Disadvantages:

    - Resources may be reserved even when no data is being sent
    - Setup time
    - Less efficient for bursty computer data


Traditional telephone networks are a classic example.


======================================================================
2.61 MESSAGE SWITCHING
======================================================================

The complete message is stored and forwarded from one intermediate
node to another.

Concept:

    A → Node 1 → Node 2 → Node 3 → B


Each node may store the entire message before forwarding it.


Advantages:

    - No dedicated circuit required


Disadvantages:

    - Large storage requirements
    - High delay


It is mainly a historical concept.


======================================================================
2.62 PACKET SWITCHING
======================================================================

A message is divided into smaller units called packets.

Concept:

    Message
       ↓
    Packet 1
    Packet 2
    Packet 3
       ↓
    Network
       ↓
    Destination


Packets share network resources with packets from other flows.


Advantages:

    - Efficient resource utilization
    - Good for bursty computer traffic
    - Supports many simultaneous users


The Internet uses packet switching.


======================================================================
2.63 DATAGRAM NETWORK
======================================================================

In a datagram network, each packet is independently forwarded.

Concept:

    Packet 1 → Path A
    Packet 2 → Path B
    Packet 3 → Path A


Packets can potentially take different paths.


IP networks operate fundamentally using a datagram model.


======================================================================
2.64 VIRTUAL CIRCUIT
======================================================================

A logical path is established before data transfer, and packets
belonging to the logical connection generally follow that path.


Concept:

    Establish logical path
           ↓
    Packet 1 ──→
    Packet 2 ──→
    Packet 3 ──→
           ↓
       Destination


It provides some circuit-like characteristics while using packet
switching.


======================================================================
2.65 CIRCUIT vs PACKET SWITCHING
======================================================================

    Circuit Switching:
        Dedicated resources/path for a session.

    Packet Switching:
        Network resources are shared among packets/flows.


Modern computer networks are predominantly packet-switched.


======================================================================
2.66 MULTIPLEXING
======================================================================

Multiplexing allows multiple signals/communications to share a
common communication resource.


Concept:

    Source 1 ──┐
    Source 2 ──┤
    Source 3 ──┼──→ Multiplexer → Shared Link
    Source 4 ──┘


At the other side:

    Shared Link
        ↓
    Demultiplexer
      / | | \
     /  | |  \
    D1 D2 D3 D4


Main concepts:

    - FDM
    - TDM
    - WDM


======================================================================
2.67 FDM
======================================================================

FDM = Frequency Division Multiplexing

Different signals use different frequency bands.


Concept:

    Frequency
       ↑
       |
    Ch4 |████
    Ch3 |    ████
    Ch2 |        ████
    Ch1 |            ████
       +----------------------→


Each communication gets a different frequency range.


======================================================================
2.68 TDM
======================================================================

TDM = Time Division Multiplexing

Users share the same channel by using different time slots.


Concept:

    Time →
    | A | B | C | A | B | C |


A, B and C take turns using the channel.


Types include:

    - Synchronous TDM
    - Statistical TDM


======================================================================
2.69 WDM
======================================================================

WDM = Wavelength Division Multiplexing

Used primarily with fiber optic communication.

Different optical wavelengths carry different channels.


Concept:

    λ1 → Channel 1
    λ2 → Channel 2
    λ3 → Channel 3
    λ4 → Channel 4


This allows very high capacity on optical fiber.


======================================================================
2.70 ERROR AND NOISE — INTRODUCTION
======================================================================

During transmission, signals can be affected by unwanted effects.

Examples:

    - Noise
    - Interference
    - Attenuation
    - Distortion


These can cause communication errors.


======================================================================
2.71 ATTENUATION
======================================================================

Attenuation means loss/reduction of signal strength as it travels.

Concept:

    Strong signal
         ↓
    Transmission medium
         ↓
    Weaker signal


Factors:

    - Distance
    - Medium properties
    - Frequency


Amplifiers/repeaters or other appropriate technologies can compensate
for signal loss in some systems.


======================================================================
2.72 NOISE
======================================================================

Noise is unwanted electrical/electromagnetic energy that can affect
a signal.

Types/concepts:

    - Thermal noise
    - Crosstalk
    - Impulse noise
    - Electromagnetic interference


Noise can reduce communication quality.


======================================================================
2.73 DISTORTION
======================================================================

Distortion occurs when the shape of a signal changes during
transmission.

Causes can include:

    - Different frequency components experiencing different effects
    - Medium characteristics
    - Nonlinear behavior


======================================================================
2.74 SIGNAL-TO-NOISE RATIO
======================================================================

SNR = Signal-to-Noise Ratio

It compares useful signal power to noise power.

Formula:

    SNR = Signal Power / Noise Power


In decibels:

    SNR(dB) = 10 log10(S/N)


Higher SNR generally means a cleaner signal.


Example:

    S = 100
    N = 1

    SNR = 100/1
        = 100

    SNR(dB) = 10 log10(100)
            = 20 dB


======================================================================
2.75 DECIBEL (dB)
======================================================================

Decibel is a logarithmic unit used to express ratios, especially
power or signal levels.

Power ratio:

    dB = 10 log10(P2/P1)


For voltage/current ratios under equal impedance conditions:

    dB = 20 log10(V2/V1)


Networking and communication systems frequently use dB for:

    - Gain
    - Loss
    - SNR
    - Signal levels


======================================================================
2.76 CHANNEL CAPACITY — BASIC IDEA
======================================================================

Channel capacity represents the maximum theoretical rate at which
information can be transmitted reliably under specified assumptions.


Two important theoretical concepts:

    1. Nyquist
    2. Shannon


======================================================================
2.77 NYQUIST BIT RATE
======================================================================

For an ideal noiseless channel:

    Maximum Bit Rate:

    Bit Rate = 2B log2(L)


Where:

    B = bandwidth in Hz
    L = number of signal levels


Example:

    B = 3000 Hz
    L = 2


    Bit rate
      = 2 × 3000 × log2(2)
      = 6000 bps


If:

    L = 4

    Bit rate
      = 2 × 3000 × log2(4)
      = 2 × 3000 × 2
      = 12,000 bps


======================================================================
2.78 SHANNON CAPACITY
======================================================================

For a noisy channel:

    C = B log2(1 + SNR)


Where:

    C   = channel capacity in bits/sec
    B   = bandwidth in Hz
    SNR = signal-to-noise ratio (linear, not dB)


If SNR is given in dB:

    SNR_linear = 10^(SNR_dB/10)


Example:

    B = 3000 Hz
    SNR = 30 dB

Convert:

    SNR_linear = 10^(30/10)
               = 1000


Therefore:

    C = 3000 log2(1001)


Approximately:

    C ≈ 29.9 Kbps


This provides a theoretical upper bound under the model's assumptions.


======================================================================
2.79 NYQUIST vs SHANNON
======================================================================

NYQUIST:

    Ideal/noiseless channel
    Considers:
        - Bandwidth
        - Number of signal levels


    C = 2B log2(L)


SHANNON:

    Noisy channel
    Considers:
        - Bandwidth
        - SNR


    C = B log2(1 + SNR)


IMPORTANT FOR GATE/INTERVIEWS:

    Nyquist → noiseless
    Shannon → noisy


======================================================================
2.80 IMPORTANT NUMERICAL FORMULAS
======================================================================

1. Frequency:

    f = 1/T


2. Period:

    T = 1/f


3. Wavelength:

    λ = v/f


4. Transmission delay:

    d_transmission = L/R


5. Propagation delay:

    d_propagation = Distance/Propagation Speed


6. Total nodal delay:

    d_total =
        d_processing +
        d_queuing +
        d_transmission +
        d_propagation


7. Bandwidth-delay product:

    BDP = Bandwidth × Propagation Delay


8. Bit rate:

    Bit Rate = Baud Rate × Bits/Symbol


9. Bits per symbol:

    Bits/Symbol = log2(M)


10. Nyquist:

    C = 2B log2(L)


11. Shannon:

    C = B log2(1 + SNR)


12. SNR in dB:

    SNR(dB) = 10 log10(S/N)


======================================================================
2.81 SOLVED NUMERICAL — BIT RATE
======================================================================

Question:

    A communication system sends 2 bits per symbol at
    5000 baud. Find bit rate.


Given:

    Baud = 5000 symbols/sec
    Bits/symbol = 2


Formula:

    Bit Rate = Baud × Bits/Symbol


    = 5000 × 2

    = 10,000 bps


ANSWER:

    10 Kbps


======================================================================
2.82 SOLVED NUMERICAL — FREQUENCY
======================================================================

Question:

    A signal has a period of 2 ms.
    Find its frequency.


Given:

    T = 2 ms
      = 0.002 sec


Formula:

    f = 1/T


    f = 1/0.002

      = 500 Hz


ANSWER:

    500 Hz


======================================================================
2.83 SOLVED NUMERICAL — TRANSMISSION DELAY
======================================================================

Question:

    Packet size = 8,000 bits
    Link rate = 2 Mbps

Find transmission delay.


Given:

    L = 8000 bits
    R = 2,000,000 bits/sec


Formula:

    d = L/R


    = 8000/2,000,000

    = 0.004 sec

    = 4 ms


ANSWER:

    4 ms


======================================================================
2.84 SOLVED NUMERICAL — PROPAGATION DELAY
======================================================================

Question:

    Distance = 600 km
    Propagation speed = 2 × 10^8 m/s


Convert:

    600 km = 600,000 m


Formula:

    d = Distance/Speed


    = 600,000/(2 × 10^8)

    = 0.003 sec

    = 3 ms


ANSWER:

    3 ms


======================================================================
2.85 SOLVED NUMERICAL — TOTAL DELAY
======================================================================

Given:

    Processing delay = 1 ms
    Queuing delay    = 2 ms
    Transmission     = 4 ms
    Propagation      = 3 ms


Total:

    1 + 2 + 4 + 3

    = 10 ms


ANSWER:

    Total nodal delay = 10 ms


======================================================================
2.86 SOLVED NUMERICAL — BDP
======================================================================

Given:

    Bandwidth = 50 Mbps
    Propagation delay = 20 ms


Convert:

    50 Mbps = 50 × 10^6 bits/sec

    20 ms = 0.020 sec


Formula:

    BDP = Bandwidth × Delay


    = 50 × 10^6 × 0.020

    = 1,000,000 bits


ANSWER:

    BDP = 1 Mbit

    In bytes:

    1,000,000 / 8
    = 125,000 bytes

    1. Your device generates a request.

    4. Router forwards packets.
    5. Packets cross ISP networks.
    6. Packets reach the server.
    7. Server processes the request.

Communication performance depends on:

    - Bandwidth

    - Packet loss
    - Congestion
    - Server processing
    - DNS delay
    - TCP/QUIC behavior
    - TLS
    - Application processing


Therefore:

    High bandwidth does NOT automatically mean low latency.

    - Low jitter
    - Low packet loss

    BUT

The call may still have:

    - Audio distortion
    - Frozen video
    - Delay
    - Choppy communication


This demonstrates why network performance is multidimensional.

2.91 IMPORTANT INTERVIEW DIFFERENCES
======================================================================

--------------------------------------------------
Bandwidth vs Throughput
--------------------------------------------------

Bandwidth:
    Nominal/theoretical capacity.

Throughput:
    Actual successful data transfer rate.


--------------------------------------------------
Throughput vs Goodput
--------------------------------------------------

Throughput:
    Data successfully transferred at the network level.

Goodput:
    Useful application data delivered after relevant overhead
    and retransmission effects are excluded.


--------------------------------------------------
Transmission Delay vs Propagation Delay
--------------------------------------------------

Transmission:
    L/R

    Depends on:
        Packet size
        Link rate


Propagation:
    d/s

    Depends on:
        Distance
        Propagation speed


--------------------------------------------------
Bit Rate vs Baud Rate
--------------------------------------------------

Bit rate:
    Bits per second.


Baud rate:
    Symbols per second.


Relation:

    Bit rate = Baud × bits/symbol


--------------------------------------------------
Analog vs Digital
--------------------------------------------------

Analog:
    Continuous-valued signal.


Digital:
    Discrete-level representation.


--------------------------------------------------
Simplex vs Half vs Full Duplex
--------------------------------------------------

Simplex:
    One-way.


Half-duplex:
    Two-way, but not simultaneously.


Full-duplex:
    Two-way simultaneously.


--------------------------------------------------
Synchronous vs Asynchronous
--------------------------------------------------

Synchronous:
    Coordinated timing/block-oriented transmission.


Asynchronous:
    No continuous shared timing; units can be individually framed.


======================================================================
2.92 GATE-LEVEL CONCEPTS TO REMEMBER
======================================================================

VERY IMPORTANT:

    1. Transmission delay = L/R

    2. Propagation delay = d/s

    3. Total delay includes:
           Processing
           Queuing
           Transmission
           Propagation

    4. Transmission delay does not directly depend on distance.

    5. Propagation delay does not directly depend on packet size.

    6. Increasing link rate reduces transmission delay.

    7. Increasing physical distance increases propagation delay.

    8. BDP = Bandwidth × Propagation Delay.

    9. Bit rate and baud rate are not necessarily equal.

   10. Nyquist is for noiseless channel analysis.

   11. Shannon considers noise/SNR.

   12. High bandwidth does not guarantee low latency.

   13. High throughput does not necessarily mean low latency.

   14. Packet switching is fundamental to the Internet.


======================================================================
2.93 COMMON MISTAKES
======================================================================

MISTAKE 1:

    "Bandwidth = actual download speed."

CORRECT:

    Bandwidth represents capacity; actual throughput may be lower.


MISTAKE 2:

    "Propagation delay depends on packet size."

CORRECT:

    Propagation delay mainly depends on distance and propagation speed.


MISTAKE 3:

    "Transmission delay depends on distance."

CORRECT:

    Transmission delay = L/R.

    Distance primarily affects propagation delay.


MISTAKE 4:

    "Bit rate always equals baud rate."

CORRECT:

    Only when each symbol represents exactly one bit.


MISTAKE 5:

    "Full duplex means faster Internet."

CORRECT:

    Full duplex means simultaneous two-way communication.
    It does not by itself define Internet speed.


MISTAKE 6:

    "Fiber uses electrical signals."

CORRECT:

    Fiber uses optical/light transmission.


MISTAKE 7:

    "Wi-Fi is the Internet."

CORRECT:

    Wi-Fi is a wireless networking technology.
    Internet is a global interconnected system of networks.
