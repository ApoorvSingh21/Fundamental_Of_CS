1.1 WHAT IS A COMPUTER?
======================================================================

A computer is an electronic device that:

    INPUT
      ↓
    PROCESSING
      ↓
    OUTPUT
      ↓
    STORAGE

Examples:
    - Desktop
    - Laptop
    - Smartphone
    - Server
    - ATM
    - IoT device
    - Smart TV

A computer can process and store information, but when multiple
computers need to communicate or share resources, we need networking.


======================================================================
1.2 WHAT IS A COMPUTER NETWORK?
======================================================================

Definition:

A computer network is a collection of interconnected computing devices
that communicate with each other and share data, resources and services
using communication links and predefined rules called protocols.


Simple definition:

    Computer Network
          =
    Devices + Communication Links + Protocols


Example:

    Computer A
         |
         | Ethernet/Wi-Fi
         |
    Network Switch
       /       \
      /         \
Computer B    Computer C


The computers can communicate and exchange information.


REAL-WORLD EXAMPLE:

Suppose:

    Laptop A wants to send a file to Laptop B.

Without a network:

    Laptop A  XXXXXXXXX  Laptop B

With a network:

    Laptop A
       |
       | Network
       |
    Laptop B

Now data can travel from A to B.


======================================================================
1.3 WHAT DOES "CONNECTED" MEAN?
======================================================================

Two devices are connected when there is a mechanism through which
they can exchange information.

Connection can be:

    1. Wired
       - Ethernet cable
       - Fiber optic cable
       - Coaxial cable

    2. Wireless
       - Wi-Fi
       - Bluetooth
       - Cellular network
       - Microwave
       - Satellite


Example:

    Laptop
       |
       | Wi-Fi
       ↓
    Router
       |
       | Fiber/Ethernet
       ↓
    Internet


======================================================================
1.4 WHY DO WE NEED COMPUTER NETWORKS?
======================================================================

Networks exist because computers need to communicate and share resources.


MAIN PURPOSES:

1. DATA SHARING
----------------

Users can transfer:

    - Documents
    - Images
    - Videos
    - Programs
    - Databases


Example:

    Employee A
        |
        ↓
    Company Network
        |
        ↓
    Employee B

Employee A can send a document to Employee B.


2. RESOURCE SHARING
-------------------

Networks allow multiple users to share resources.

Examples:

    - Printers
    - Storage
    - Internet connection
    - Servers
    - Databases
    - Applications


Example:

             Printer
                |
                |
        -------------------
        |        |        |
       PC1      PC2      PC3

Three computers can use one network printer.


3. COMMUNICATION
----------------

Networks enable:

    - Email
    - Chat
    - Video calls
    - Voice calls
    - Messaging
    - Collaboration


4. INTERNET ACCESS
------------------

A network allows devices to access the Internet.

Example:

    Laptop
       ↓
    Wi-Fi Router
       ↓
    ISP
       ↓
    Internet
       ↓
    Web Server


5. CENTRALIZED DATA
-------------------

Organizations can store data centrally.

Example:

    Employee PCs
      |   |   |
      |   |   |
      +---+---+
          |
          ↓
       Database
        Server


6. REMOTE ACCESS
----------------

A user can access systems from another location.

Example:

    Employee
       |
       | Internet
       ↓
    Company VPN
       |
       ↓
    Internal Server


7. DISTRIBUTED COMPUTING
------------------------

A large task can be distributed among multiple computers.

Example:

    Computer 1 ──┐
    Computer 2 ──┤
    Computer 3 ──┼──→ Distributed System
    Computer 4 ──┤
    Computer 5 ──┘


======================================================================
1.5 BASIC NETWORKING TERMINOLOGY
======================================================================

Before learning networking deeply, you must understand these terms.


------------------------
A. NODE
------------------------

A node is any device that participates in a network.

Examples:

    - Computer
    - Router
    - Switch
    - Printer
    - Server
    - IoT device


Example:

    PC1 ---- Switch ---- PC2
                 |
                 |
               Router

Possible nodes:
    PC1
    PC2
    Switch
    Router


------------------------
B. HOST
------------------------

A host is a network-connected device that can send or receive data.

Examples:

    - Laptop
    - Desktop
    - Server
    - Smartphone


Important:

    Every host is a network device,
    but not every network device is necessarily considered
    an end host.

Example:

    PC -------- Router -------- Server

    PC      = Host
    Server  = Host
    Router  = Network infrastructure device


------------------------
C. CLIENT
------------------------

A client is a device or application that requests a service.

Example:

    Browser → requests webpage → Web Server

Here:

    Browser = Client
    Web Server = Server


------------------------
D. SERVER
------------------------

A server is a system that provides a service or resource to clients.

Examples:

    Web Server
    Database Server
    File Server
    Mail Server
    DNS Server
    DHCP Server


Example:

    Client 1 ──┐
    Client 2 ──┼──→ Web Server
    Client 3 ──┘


------------------------
E. PEER
------------------------

A peer is a device that can communicate directly with another device
and may provide and consume resources.

This is common in peer-to-peer networks.


Example:

    PC A  ←────→  PC B
      ↑             ↑
      └──────→──────┘
          PC C

Each device may act as both client and server.


------------------------
F. LINK
------------------------

A link is the communication path between two network devices.

Examples:

    Ethernet cable
    Fiber cable
    Wireless radio link


Example:

    PC ───────── Switch

    The connection between PC and Switch is a link.


------------------------
G. PACKET
------------------------

A packet is a formatted unit of data transmitted over a network.

Example:

    Original message:
        "HELLO"

    Network data:
        Packet 1
        Packet 2
        Packet 3
        ...

Packets contain information needed to deliver data.


------------------------
H. PROTOCOL
------------------------

A protocol is a set of rules that defines how devices communicate.

Examples:

    TCP
    IP
    HTTP
    HTTPS
    DNS
    DHCP
    FTP
    SSH


Analogy:

Human communication:

    Person A: "Hello"
    Person B: "Hello"

Computers also require agreed rules.

Without common rules:

    Device A → ??? ← Device B

With protocols:

    Device A → Protocol Rules → Device B


IMPORTANT:

Protocol = Rules of communication.


------------------------
I. PORT
------------------------

A port identifies a logical communication endpoint associated with
a network service on a host.

Examples:

    HTTP  → 80
    HTTPS → 443
    SSH   → 22
    DNS   → 53


Example:

    Server IP:
        192.168.1.10

    HTTPS:
        192.168.1.10:443


The IP identifies the host.

The port identifies the service/application endpoint.


------------------------
J. SOCKET
------------------------

A socket is an endpoint used by an application for network
communication.

A simplified representation:

    IP Address + Port + Transport Protocol

Example:

    192.168.1.10 : 443 / TCP


Socket programming allows applications to communicate over networks.

1.6 NETWORK COMPONENTS
======================================================================

A network typically contains:

    1. End devices
    2. Network devices
    3. Transmission media
    4. Protocols
    5. Network services


------------------------
1. END DEVICES
------------------------

End devices are devices used by users or applications.

Examples:

    - PC
    - Laptop
    - Smartphone
    - Server
    - Printer
    - IoT device


------------------------
2. NETWORK DEVICES
------------------------

These devices help move or control network traffic.

Examples:

    - Switch
    - Router
    - Access Point
    - Firewall
    - Gateway
    - Repeater
    - Modem


------------------------
3. TRANSMISSION MEDIA
------------------------

Media carry signals between devices.

Wired:

    - UTP
    - STP
    - Coaxial
    - Fiber optic

Wireless:

    - Radio
    - Microwave
    - Infrared
    - Satellite


------------------------
4. PROTOCOLS
------------------------

Protocols define communication rules.

Examples:

    TCP
    IP
    HTTP
    DNS
    DHCP
    ARP
    ICMP
    FTP
    SSH


------------------------
5. NETWORK SERVICES
------------------------

Examples:

    DNS
    DHCP
    Web service
    Email
    File sharing
    Authentication
    Directory services

1.7 TYPES OF NETWORKS

Networks can be classified according to:

    - Geographical coverage

The important classifications are:

    PAN

======================================================================
1.8 PAN — PERSONAL AREA NETWORK
======================================================================

PAN = Personal Area Network

It is a small network around an individual.

Typical range:
    Very small / personal area.

Examples:

    Smartphone
       |
       | Bluetooth
       ↓
    Wireless Earbuds

Another example:

    Smartphone
       |
       | Bluetooth
       ↓
    Smartwatch


Technologies:

    - Bluetooth
    - USB
    - NFC
    - Personal Wi-Fi hotspot


Use:

    - Connecting personal devices
    - Wearable devices
    - File transfer
    - Personal hotspot


======================================================================
1.9 LAN — LOCAL AREA NETWORK
======================================================================

LAN = Local Area Network

A LAN connects devices within a limited geographical area.

Examples:

    - Home
    - Office
    - Computer lab
    - School building
    - Small campus area


Example:

                 Router
                   |
                Switch
              /   |   \
             /    |    \
           PC1   PC2   PC3


Characteristics:

    - Small geographical area
    - Usually high speed
    - Privately managed
    - Low latency compared with WAN
    - Ethernet/Wi-Fi commonly used


Example:

    Your college computer lab
        ↓
    Usually a LAN.


======================================================================
1.10 WLAN — WIRELESS LAN
======================================================================

WLAN = Wireless Local Area Network

A WLAN is a LAN using wireless communication.

Most commonly:

    Wi-Fi


Example:

             Internet
                |
             Router/AP
           /    |    \
         Wi-Fi Wi-Fi Wi-Fi
          /      |      \
       Laptop  Phone   Tablet


LAN:
    May use wired Ethernet.

WLAN:
    Uses wireless connectivity.


======================================================================
1.11 CAN — CAMPUS AREA NETWORK
======================================================================

CAN = Campus Area Network

It connects multiple LANs across a campus or organization.

Example:

    Building A LAN
           |
           |
    Building B LAN
           |
           |
    Building C LAN
           |
           |
    Central Network


Examples:

    - University campus
    - Corporate campus
    - Research institution


Important:

    CAN here means Campus Area Network.

    Do not confuse it with:
        CAN = Controller Area Network
    used in automotive systems.


======================================================================
1.12 MAN — METROPOLITAN AREA NETWORK
======================================================================

MAN = Metropolitan Area Network

It covers a larger area than a LAN, commonly across a city or
metropolitan region.

Conceptual structure:

    LAN A ─────┐
               |
    LAN B ─────┼──→ MAN
               |
    LAN C ─────┘


Examples:

    - City-wide network
    - Metropolitan ISP infrastructure


Size:

    PAN < LAN < CAN/MAN < WAN

The exact boundaries can vary by context.


======================================================================
1.13 WAN — WIDE AREA NETWORK
======================================================================

WAN = Wide Area Network

WAN covers a large geographical area.

Examples:

    - Country
    - Multiple countries
    - Continents
    - Global networks


Example:

    Office India
         |
         |
       WAN
         |
         |
    Office USA
         |
         |
    Office Europe


The Internet is the world's largest interconnected
network of networks.


WAN technologies can include:

    - MPLS
    - Leased lines
    - Broadband
    - Cellular
    - Satellite
    - SD-WAN


======================================================================
1.14 SAN — STORAGE AREA NETWORK
======================================================================

SAN = Storage Area Network

It is a specialized high-speed network used to provide access to
storage resources.

Common in:

    - Data centers
    - Enterprises
    - Large organizations


Concept:

    Servers
      |  |  |
      |  |  |
      +--+--+
         |
        SAN
         |
      Storage


Technologies can include:

    - Fibre Channel
    - iSCSI


IMPORTANT:

    SAN is different from a normal LAN.

    LAN:
        Connects computers/devices generally.

    SAN:
        Specifically focuses on storage connectivity.


======================================================================
1.15 VPN — VIRTUAL PRIVATE NETWORK
======================================================================

VPN = Virtual Private Network

A VPN creates a logical/private communication path over another
network, commonly the Internet.

Example:

    Employee
       |
       | Internet
       ↓
    VPN Tunnel
       |
       ↓
    Company Network


Uses:

    - Secure remote access
    - Site-to-site connectivity
    - Privacy
    - Connecting remote networks


Important:

    VPN is not primarily a geographical network category like
    LAN or WAN.

    It is a technology for creating a private logical connection
    over an underlying network.

1.17 NETWORK ARCHITECTURE
======================================================================

Network architecture describes how devices and services are organized
and how they communicate.


Two fundamental models:

    1. Client-Server
    2. Peer-to-Peer


======================================================================
1.18 CLIENT-SERVER ARCHITECTURE
======================================================================

In client-server architecture:

    Client → requests service
    Server → provides service


Example:

    User
      |
      ↓
    Browser
      |
      | HTTP/HTTPS request
      ↓
    Web Server
      |
      ↓
    Response
      |
      ↓
    Browser


Another example:

    Client PC
       |
       ↓
    Database Server


Characteristics:

    - Centralized services
    - Easier management
    - Centralized security
    - Centralized data
    - Can scale using multiple servers


Advantages:

    1. Centralized management
    2. Better control
    3. Easier backup
    4. Easier security management
    5. Suitable for large organizations


Disadvantages:

    1. Server can become bottleneck
    2. Server failure can affect clients
    3. Infrastructure cost can be higher


Examples:

    - Web applications
    - Banking systems
    - Email systems
    - Database systems
    - Cloud applications


======================================================================
1.19 PEER-TO-PEER ARCHITECTURE
======================================================================

P2P = Peer-to-Peer

In a P2P network, devices can communicate directly and may act as
both clients and providers of resources.

Example:

             PC A
            ↗    ↘
           ↙      ↘
         PC B ←──→ PC C


There is no requirement for one central server for every interaction.


Advantages:

    - Simple for small networks
    - Resource sharing
    - No mandatory central server
    - Can distribute workloads


Disadvantages:

    - Difficult centralized management
    - Security can be harder
    - Backup can be harder
    - Less suitable for many enterprise applications


Examples:

    - Some file-sharing systems
    - Some distributed applications
    - Blockchain networks use P2P concepts


======================================================================
1.20 CLIENT-SERVER vs P2P
======================================================================

CLIENT-SERVER:

    Client ──→ Server
    Client ──→ Server
    Client ──→ Server

    Centralized service model


P2P:

    Peer ←→ Peer
      ↕      ↕
    Peer ←→ Peer

    Distributed interaction model


Comparison:

    Feature              Client-Server       P2P
    ------------------------------------------------------
    Central server       Usually yes         Not required
    Management           Centralized         Distributed
    Security control     Easier              More difficult
    Scalability          High with design    Depends on system
    Administration       Easier              More difficult
    Typical use          Web/DB/enterprise   Distributed sharing


======================================================================
1.21 NETWORK TOPOLOGY
======================================================================

Topology describes how devices are arranged and interconnected.

Two important concepts:

    1. Physical topology
    2. Logical topology


PHYSICAL TOPOLOGY:

    Actual physical arrangement of cables/devices.


LOGICAL TOPOLOGY:

    How data logically flows through the network.


Common topologies:

    - Bus
    - Star
    - Ring
    - Mesh
    - Tree
    - Hybrid
    - Point-to-point
    - Point-to-multipoint


======================================================================
1.22 BUS TOPOLOGY
======================================================================

All devices share a common communication medium.

Example:

    PC1     PC2     PC3     PC4
     |       |       |       |
     +-------+-------+-------+
             Common Bus


Advantages:

    - Simple
    - Less cable required
    - Historically inexpensive


Disadvantages:

    - Shared medium
    - Collision concerns
    - Failure of main cable can affect network
    - Difficult troubleshooting
    - Poor scalability


Modern Ethernet LANs generally do not use the old shared-coaxial
bus topology.


======================================================================
1.23 STAR TOPOLOGY
======================================================================

All devices connect to a central device.

Example:

                 PC1
                  |
                  |
        PC2 ---- Switch ---- PC3
                  |
                  |
                 PC4


Central device may be:

    - Switch
    - Access point
    - Hub in older networks


Advantages:

    - Easy to install
    - Easy to troubleshoot
    - One end-device cable failure usually affects only that device
    - Easy to expand


Disadvantages:

    - Central device is critical
    - More cable than bus topology


Most modern wired Ethernet LANs commonly use a star or
hierarchical star arrangement.


======================================================================
1.24 RING TOPOLOGY
======================================================================

Devices form a circular path.

Example:

          PC1
        /     \
      PC4      PC2
        \     /
          PC3


Data travels around the ring according to the technology.


Advantages:

    - Predictable access in some implementations
    - Can provide organized transmission


Disadvantages:

    - A failure can affect communication depending on implementation
    - Adding/removing devices can be more complicated


Historical examples include token-ring concepts.


======================================================================
1.25 MESH TOPOLOGY
======================================================================

Devices have multiple interconnections.

Full mesh:

    Every device connects to every other device.


Example:

       A -------- B
       |\        /|
       | \      / |
       |  \    /  |
       |   \  /   |
       |    \/    |
       |    /\    |
       |   /  \   |
       |  /    \  |
       | /      \ |
       C -------- D


For n devices in a full mesh:

    Number of links = n(n - 1) / 2


Example:

    n = 4

    Links = 4(4-1)/2
          = 4×3/2
          = 6


Advantages:

    - High redundancy
    - Multiple paths
    - High fault tolerance


Disadvantages:

    - Expensive
    - More cables/interfaces
    - Complex management


Used where redundancy is important.


======================================================================
1.26 TREE TOPOLOGY
======================================================================

Tree topology is hierarchical.

Example:

                    Core
                     |
              -------+-------
              |             |
            Switch         Switch
           /    \          /    \
         PC1    PC2      PC3    PC4


Common in enterprise networks.


Advantages:

    - Hierarchical
    - Scalable
    - Easier management


Disadvantages:

    - Higher-level failure can affect branches
    - More complex than simple star


======================================================================
1.27 HYBRID TOPOLOGY
======================================================================

Combination of two or more topologies.

Example:

    Star + Mesh
    Star + Tree
    Ring + Star


Enterprise networks commonly contain combinations of topologies.


======================================================================
1.28 POINT-TO-POINT TOPOLOGY
======================================================================

Direct connection between two devices.

Example:

    Router A ================= Router B


Advantages:

    - Simple
    - Dedicated link
    - Easy to understand


Used in:

    - Router-to-router links
    - Dedicated WAN connections
    - Direct device communication


======================================================================
1.29 POINT-TO-MULTIPOINT
======================================================================

One central device communicates with multiple endpoints.

Example:

                  Access Point
                 /     |      \
                /      |       \
             Laptop  Phone    Tablet


Common concept in:

    - Wireless networks
    - Some WAN technologies

1.30 NETWORK CHARACTERISTICS

A good network should consider:

    1. Performance
    2. Reliability
    3. Scalability
    4. Security
    5. Availability

======================================================================
1.31 PERFORMANCE
======================================================================

Performance describes how effectively a network transfers data.


Important metrics:

    Bandwidth
    Throughput
    Latency
    Jitter
    Packet loss


BANDWIDTH:

    Maximum theoretical data-carrying capacity of a link/channel.

Example:

    100 Mbps Ethernet


THROUGHPUT:

    Actual rate at which data is successfully transferred.


Example:

    Link capacity = 100 Mbps
    Actual throughput = 85 Mbps


LATENCY:

    Time taken for data to travel from source to destination
    or for a request/response interaction, depending on context.


Example:

    Ping RTT = 20 ms


JITTER:

    Variation in packet delay.

Important for:

    - Voice calls
    - Video conferencing
    - Online gaming


PACKET LOSS:

    Packets that fail to reach the destination.


Example:

    Sent = 100 packets
    Received = 98 packets

    Packet loss = 2%


These concepts will be studied deeply in later chapters.


======================================================================
1.32 RELIABILITY
======================================================================

Reliability means the network should provide correct and consistent
communication over time.


Factors:

    - Hardware quality
    - Redundancy
    - Error detection
    - Error recovery
    - Backup links
    - Proper configuration


Example:

    Router A
       |
       | Primary link
       ↓
    Router B

If the primary link fails:

    Router A
       |
       | Backup link
       ↓
    Router B


Redundancy improves reliability.


======================================================================
1.33 SCALABILITY
======================================================================

Scalability means the network can grow without requiring a complete
redesign.


Example:

Small company:

    20 users


Later:

    200 users


Later:

    2,000 users


A scalable design should support growth.


Scalability considerations:

    - Addressing
    - Routing
    - Switching
    - Bandwidth
    - Security
    - Management
    - Infrastructure


======================================================================
1.34 AVAILABILITY
======================================================================

Availability means how often a system/network is operational and
accessible when needed.


Example:

    Network available:
        99.9%


Higher availability generally requires:

    - Redundancy
    - Backup systems
    - Monitoring
    - Failover
    - Reliable hardware


======================================================================
1.35 FAULT TOLERANCE
======================================================================

Fault tolerance means the network can continue operating even when
some components fail.


Example:

              Router A
             /        \
            /          \
         Link 1       Link 2
          /              \
       Server ---------- Server


If one path fails, another path can be used.


Fault tolerance is especially important in:

    - Banking
    - Hospitals
    - Data centers
    - Cloud infrastructure
    - Telecom networks


======================================================================
1.36 NETWORK SECURITY
======================================================================

Network security protects:

    - Data
    - Devices
    - Applications
    - Users
    - Network infrastructure


Main security goals:

    Confidentiality
    Integrity
    Availability


This is known as:

    CIA TRIAD


CONFIDENTIALITY:

    Only authorized users should access information.


INTEGRITY:

    Data should not be improperly modified.


AVAILABILITY:

    Systems and data should be accessible when required.


Example:

    User
      |
      ↓
    Firewall
      |
      ↓
    Internal Network


Security mechanisms include:

    - Firewall
    - Authentication
    - Encryption
    - VPN
    - IDS
    - IPS
    - Access control
    - Network segmentation


Security will be studied deeply in later chapters.

======================================================================

Internet:

    A global system of interconnected networks that communicate
    using standardized protocols, especially the Internet Protocol

Think of the Internet as:

    Network
       +
    Network
       +
    Network
       +
    Network
       +
    Network
       ↓
    INTERNET


Important distinction:

    Internet ≠ a single physical network.

    It is an interconnected collection of many networks.


Example:

    Home Network
         |
         ↓
       ISP
         |
         ↓
    ISP Network
         |
         ↓
    Internet Backbone
         |
         ↓
    Data Center
         |
         ↓
    Web Server

1.38 INTRANET

An intranet is a private network used within an organization.

Example:

    Company employees
            |
            ↓
        Intranet
            |
       ------------
       |          |
     HR App    Internal DB

1.39 EXTRANET
======================================================================

An extranet allows selected external users or organizations to access
certain private organizational resources.

Example:

    Company
       |
       ↓
    Extranet
       |
       ↓
    Authorized Supplier


The supplier gets controlled access rather than unrestricted access.


======================================================================
1.40 INTERNET vs INTRANET vs EXTRANET
======================================================================

INTERNET:

    Public/global network environment


INTRANET:

    Private organizational network


EXTRANET:

    Controlled access from authorized external parties


Simple:

    INTERNET
        ↓
    Public

    INTRANET
        ↓
    Internal

    EXTRANET
        ↓
    Controlled external access

1.41 WIRED NETWORK
======================================================================

A wired network uses physical transmission media.

Examples:

    - Ethernet
    - Fiber optic
    - Coaxial


Example:

    PC ===== Ethernet Cable ===== Switch


Advantages:

    - Stable connection
    - Usually lower interference than wireless
    - High throughput
    - Better predictable performance
    - Good security when physically controlled


Disadvantages:

    - Cabling required
    - Less mobility
    - Installation can be difficult

1.42 WIRELESS NETWORK
======================================================================

A wireless network transmits data using electromagnetic waves rather
than a physical cable for the access link.


Examples:

    - Wi-Fi
    - Bluetooth
    - Cellular
    - Microwave
    - Satellite


Example:

    Laptop )))))) Wi-Fi )))))) Access Point


Advantages:

    - Mobility
    - Easy deployment
    - Less cabling
    - Convenient


Disadvantages:

    - Interference
    - Signal attenuation
    - Security considerations
    - Variable performance
    - Limited range depending on technology

1.46 NETWORK COMMUNICATION — BIG PICTURE
======================================================================

Suppose:

    Computer A wants to communicate with Computer B.


Step 1:
    Application creates data.

Step 2:
    Transport layer prepares communication.

Step 3:
    Network layer determines addressing/routing.

Step 4:
    Data Link layer prepares frames.

Step 5:
    Physical layer transmits bits.

Conceptually:

    Application Data
          ↓
       Segment
          ↓
       Packet
          ↓
        Frame
          ↓
         Bits
          ↓
      Physical medium


At destination:

         Bits
          ↓
        Frame
          ↓
       Packet
          ↓
       Segment
          ↓
    Application Data


This process is called:

    ENCAPSULATION
        and
    DECAPSULATION

It will be studied deeply in Chapter 3.

1.47 IMPORTANT DIFFERENCE: NETWORK vs INTERNET
======================================================================

NETWORK:

    A collection of connected devices that communicate with each other.


INTERNET:

    A global interconnected system of networks.


Example:

    Your home Wi-Fi network = Network

    Global Internet = Network of networks


======================================================================
1.48 IMPORTANT DIFFERENCE: HOST vs NODE
======================================================================

NODE:

    Any participating network device.


HOST:

    A network-connected endpoint capable of sending/receiving data.


Simplified interview answer:

    Node = broader term.

    Host = typically an end system participating in network
           communication.


======================================================================
1.49 IMPORTANT DIFFERENCE: BANDWIDTH vs SPEED
======================================================================

Bandwidth:

    Capacity of a communication link.


Throughput:

    Actual successful data transfer rate.


Example:

    Bandwidth = 100 Mbps
    Throughput = 80 Mbps


Therefore:

    Bandwidth ≠ necessarily actual throughput.


======================================================================
1.50 IMPORTANT DIFFERENCE: INTERNET vs WEB
======================================================================

INTERNET:

    Global networking infrastructure and interconnected networks.


WORLD WIDE WEB (WWW):

    A service/application system running over the Internet.


Other services running over the Internet include:

    - Email
    - DNS
    - SSH
    - VoIP
    - File transfer
    - Streaming


Therefore:

    Internet ≠ Web


The Web is one of the major services that uses the Internet.


======================================================================
1.51 IMPORTANT DIFFERENCE: ROUTER vs SWITCH
======================================================================

SWITCH:

    Primarily connects devices within a LAN and forwards Ethernet
    frames based on MAC addresses.


ROUTER:

    Connects different IP networks and forwards packets based on
    IP addresses/routing information.


Simplified:

    PC ── Switch ── PC
            |
            |
          Router
            |
            |
        Another Network


Switch:
    Mainly Layer 2

Router:
    Mainly Layer 3


Detailed switching/routing comes later.

1.57 INTERVIEW QUESTIONS
======================================================================

Q1. What is a computer network?

Answer:

    A computer network is a collection of interconnected devices
    that communicate and share data, resources and services using
    communication links and protocols.


Q2. Why do we need computer networks?

Answer:

    Networks are required for communication, data sharing,
    resource sharing, remote access, centralized services,
    Internet access and distributed computing.


Q3. What is a protocol?

Answer:

    A protocol is a set of rules that defines how network devices
    communicate and exchange data.


Q4. What is a node?

Answer:

    A node is a device or endpoint that participates in a network.


Q5. What is a host?

Answer:

    A host is a network-connected end system capable of
    communicating over the network.


Q6. What is the difference between a client and server?

Answer:

    A client requests a service, while a server provides a service.


Q7. What is LAN?

Answer:

    LAN is a Local Area Network that connects devices within a
    relatively limited geographical area such as a home, office
    or laboratory.


Q8. What is WAN?

Answer:

    WAN is a Wide Area Network that connects networks across
    large geographical areas.


Q9. What is topology?

Answer:

    Topology describes the arrangement and interconnection of
    devices and links in a network.


Q10. Which topology is commonly used in modern Ethernet LANs?

Answer:

    Star or hierarchical star topology is common.


Q11. What is the difference between Internet and Web?

Answer:

    The Internet is the global interconnected network infrastructure,
    while the Web is a service that operates over the Internet.


Q12. What is a VPN?

Answer:

    A VPN provides a logical/private communication path over an
    underlying network, commonly the Internet, often using
    tunneling and encryption.


Q13. What is scalability?

Answer:

    Scalability is the ability of a network to grow while continuing
    to meet performance, management and reliability requirements.


Q14. What is fault tolerance?

Answer:

    Fault tolerance is the ability of a network to continue operating
    despite failure of some components.


Q15. What is bandwidth?

Answer:

    Bandwidth represents the capacity of a communication link.


Q16. What is throughput?

Answer:

    Throughput is the actual rate at which data is successfully
    transferred.


Q17. What is latency?

Answer:

    Latency is the delay associated with data communication.

1.58 COMMON BEGINNER MISTAKES
======================================================================

MISTAKE 1:

    "Internet and Wi-Fi are the same."

CORRECT:

    Wi-Fi is a wireless networking technology.

    Internet is a global interconnected network/service environment.


MISTAKE 2:

    "Router gives Internet."

CORRECT:

    A router forwards packets between networks.

    Internet access is normally provided through an ISP and
    associated network infrastructure.


MISTAKE 3:

    "IP address and MAC address are the same."

CORRECT:

    IP = logical network-layer addressing.

    MAC = link-layer hardware/interface addressing concept.


MISTAKE 4:

    "Bandwidth means actual speed."

CORRECT:

    Bandwidth is capacity.

    Actual performance depends on throughput and other factors.


MISTAKE 5:

    "Every network requires a server."

CORRECT:

    No.

    Peer-to-peer networks can operate without a dedicated
    central server for all communication.


MISTAKE 6:

    "Switch and router are the same."

CORRECT:

    Switches primarily forward frames within LANs.

    Routers forward packets between IP networks.
